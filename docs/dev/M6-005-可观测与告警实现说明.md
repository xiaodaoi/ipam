# M6-005 可观测与告警实现说明

## 1. 指标端点

`GET /metrics`（无需认证，建议仅监控网访问）：

- `ipam_build_info{version}` / `ipam_uptime_seconds`
- `ipam_http_requests_total{method,status}` / `ipam_http_request_duration_seconds_sum|count`
- `ipam_component_up{component="postgres|clickhouse|kea"}`（1/0）
- `ipam_host_cpu_usage_percent`、`ipam_host_cpu_cores`
- `ipam_host_memory_used_bytes|total_bytes`
- `ipam_host_disk_used_percent{mount,device,fstype}`
- `ipam_host_uptime_seconds`
- `ipam_tls_cert_expiry_timestamp_seconds`（配置 TLS 证书时）

实现：`internal/module/platform/metrics.go`。HTTP 统计中间件在 RBAC 之前注册，排除 `/metrics` 自身；组件探针 1.5s 超时；未配置组件返回 0（down），不伪造健康。

## 2. 部署

主栈无需改动；监控栈为可选 profile，复用 `ipam_default` 网络：

```bash
cp observability/alertmanager.yml.example observability/alertmanager.yml
GRAFANA_ADMIN_PASSWORD='strong-password' \
docker compose -f observability/compose.observability.yaml --profile observability up -d
```

默认端口仅绑 127.0.0.1：Prometheus 9090 / Alertmanager 9093 / Grafana 3000。

## 3. 告警

`alerts.yml`：

- `IpamControlPlaneDown`（up==0 2m）
- `IpamComponentDown`（组件 3m）
- `IpamDiskWarning/Critical`（85/90%）
- `IpamMemoryHigh`（90%）
- `IpamTLSCertExpiring`（30 天）
- `IpamHTTP5xx`（5xx >1/s 5m）

Alertmanager 示例提供邮件、通用 Webhook、钉钉 Webhook；企微同理替换 URL/模板。

## 4. NTP

`install.sh` 读取 `timedatectl show -p NTPSynchronized --value`，未同步输出警告；容器继承宿主时钟，生产由宿主机 chrony/systemd-timesyncd 负责。

## 5. 验证

- `/metrics` 实测：构建信息、请求计数、组件状态、宿主指标齐全；
- 单测：`TestMetricsHandler` 校验计数/组件/内容类型/不统计自身；
- `go test ./...`、`vue-tsc`、eslint、`pnpm build` 通过；
- `docker compose -f observability/compose.observability.yaml config` 通过（需 GRAFANA_ADMIN_PASSWORD）。
