# M4-015 全站主菜单视觉统一实现说明

> 目标：所有主菜单页面共享一套视觉语言，减少「每页一个样」的拼接感，同时不改变业务逻辑与 API。

## 1. 设计对接点

| 层级 | 位置 | 说明 |
|---|---|---|
| 设计变量 | `src/styles/index.css` | `--ipam-radius`、`--ipam-gap`、`--ipam-shadow`、`--ipam-tone-*`；颜色全部引用 Vben 主题变量，明暗主题自动切换 |
| 页面骨架 | `.ipam-page` | 统一 `padding: 18px 22px 28px`、纵向 16px 间距、窄屏降级 |
| 页头 | `components/page-header.vue` | eyebrow / 图标 / 标题 / 描述 / 右侧操作区；一级页面统一使用 |
| 指标卡 | `components/stat-card.vue` | 标签、数值、单位、说明、图标、趋势、进度；仪表盘使用 |
| 卡片 | `.ipam-page .ant-card` | 12px 圆角、1px 边框、轻阴影、50px 卡头、18px 卡体；Ant Card 与自定义面板视觉对齐 |
| 表格 | `.ipam-page .ant-table` / `.ipam-table-plain` | 灰色表头、13px 正文、行 hover 主色微染、分页间距统一 |
| 工具条 | `.ipam-toolbar` | 筛选/操作区浅灰底、10px 圆角；`ipam-toolbar__spacer` 推右侧主操作 |
| 空状态 | `.ipam-empty` | 图标 + 标题 + 说明的虚线面板，替代裸文本 |
| 侧栏 | `.ipam-side-card` / `--wide` | 组织树 192px、DNS 区域 264px，sticky + 统一选中态 |

## 2. 关键代码路径

- `src/bootstrap.ts`：在 `@vben/styles` 后引入 `#/styles/index.css`。
- `src/app.vue`：`ConfigProvider` 关闭按钮中文自动空格，保持按钮文案紧凑。
- `src/preferences.ts`：默认浅色、企业蓝主色、本地默认头像、关闭上游版权。
- `src/views/dashboard/ipam/index.vue`：指标卡 + 趋势 + 健康 + 主机资源 + TopN 的完整重构。
- `src/views/{dhcp,dns,logs,system}/**`：统一 `ipam-page` + `PageHeader` + Card 标题/extra + `ipam-toolbar`。
- `src/views/_core/authentication/login.vue`、`src/layouts/auth.vue`：移除演示登录入口，固定产品文案。
- `src/views/_core/about/index.vue`：产品信息 / 核心能力 / 技术栈。
- `vite.config.ts`：开发代理目标 `http://127.0.0.1:8443/api/v1`，与生产 `/api/v1` 对齐。
