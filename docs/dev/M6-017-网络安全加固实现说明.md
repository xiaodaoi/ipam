# M6-017 网络安全加固实现说明

> 范围：控制面 API、Web 应用与配套服务的网络暴露面收敛与协议加固。与 M6-001（TLS/密钥/口令/限流基线）互补，本文只记录本次新增/调整项。

## 1. 客户端 IP 可信边界（防限流绕过 / 审计 IP 污染）

- `cmd/control-plane/main.go`：`r.SetTrustedProxies(splitList(IPAM_TRUSTED_PROXIES))`。
- 未配置时传入 `nil` → gin 不信任任何代理，`c.ClientIP()` 使用直连 `RemoteAddr`，`X-Forwarded-For` 不可伪造。
- 显式配置 CIDR/地址后，仅来自可信来源的 `X-Forwarded-*` 被采纳。
- 影响：限流桶、审计来源 IP、`req.ip` 均以可信边界为准。

## 2. 请求体大小限制

- `platform.BodyLimit(maxBytes)`（`internal/module/platform/security.go`）作用于 `/api/v1/*`：
  - 已知 `Content-Length` 超限 → 前置返回 **413**（`PAYLOAD_TOO_LARGE`，RFC 9457），并 `Connection: close`；
  - 分块/未知长度 → 包裹 `http.MaxBytesReader` 作为兜底。
- `IPAM_MAX_BODY_BYTES` 默认 1 MiB，`0` 关闭。审计中间件仍以 8 KiB 限读，互不影响。

## 3. HTTP 方法收敛

- `platform.RejectTrace()`：`TRACE`/`TRACK` → 405（`METHOD_NOT_ALLOWED`）。

## 4. 安全响应头与 CSP

- `platform.SecurityHeaders(csp...)` 在原有基础上新增：
  - `Cross-Origin-Resource-Policy: same-origin`
  - `X-Permitted-Cross-Domain-Policies: none`
  - `X-DNS-Prefetch-Control: off`
  - `X-XSS-Protection: 0`
- HSTS：`Request.TLS != nil`，或 `IPAM_FORCE_HSTS=1` 且 `X-Forwarded-Proto: https`（TLS 终结在反代之后）。
- **默认 CSP**（`platform.DefaultHTMLCSP(indexHTML)`）：
  - 启动时读取将服务的 `index.html`，用正则提取**内联 `<script>`**（无 `src`）内容并计算 `sha256-<base64>`，写入 `script-src 'self' 'sha256-...'`，**不使用 `'unsafe-inline'`**；
  - `style-src 'self' 'unsafe-inline'`（Vue 运行期注入内联样式）；
  - 允许 iconify 图标运行期取图：`connect-src`/`img-src` 含 `https://api.iconify.design`（及 simplesvg/unisvg 备用域）；**M6-018 已将图标离线化，此放行已移除**，CSP 收敛为 `connect-src 'self'` / `img-src 'self' data: blob:`。
  - `frame-ancestors 'none'`、`base-uri 'self'`、`form-action 'self'`、`object-src 'none'`。
  - 覆盖：`IPAM_SECURITY_CSP` 全量自定义；`IPAM_SECURITY_CSP_OFF=1` 关闭。
- CSP 属全局响应头；对 JSON/JS 无副作用，对 `index.html` 生效。
- 无持久化：内联脚本哈希每次启动按实际 `index.html` 重算，前端升级后自动适配。

## 5. `/metrics` 暴露面收敛

- `platform.MetricsAuth(IPAM_METRICS_TOKEN)`：设置令牌后 `/metrics` 需 `Authorization: Bearer <token>`（`subtle.ConstantTimeCompare`），否则 401；未设置则放行并打印启动告警。
- 部署：`install.sh` 生成随机令牌写入 `.env` 与 `observability/metrics_token`；`observability/prometheus.yml` 用 `authorization.credentials_file` 携带。

## 6. HTTP 服务器与 TLS 加固

- `http.Server`：
  - `MaxHeaderBytes = 64 KiB`；
  - `ReadTimeout = IPAM_HTTP_READ_TIMEOUT`（默认 60s）；
  - `WriteTimeout = IPAM_HTTP_WRITE_TIMEOUT`（默认 **0，不设**）——`/logs/tail` 为 SSE 长连接，写超时会误杀；
  - 保留 `ReadHeaderTimeout=10s`（防慢速头）、`IdleTimeout=2m`。
- TLS（`IPAM_TLS_CERT/KEY` 成对时）：
  - `MinVersion = tlsMinVersion(IPAM_TLS_MIN_VERSION)`（默认 TLS1.2，可设 1.3）；
  - `CurvePreferences = {X25519, P256}`；
  - TLS1.2 仅启用 AEAD 套件（ECDHE + AES-GCM / CHACHA20-POLY1305）。
- 启动日志打印生效摘要（tls/minTLS/超时/maxHeaderBytes、trustedProxies/bodyLimit）。

## 7. 部署与文档

- `deploy/compose/.env.example`、`compose.yaml`：新增 `IPAM_TRUSTED_PROXIES`/`IPAM_MAX_BODY_BYTES`/`IPAM_METRICS_TOKEN`/`IPAM_TLS_MIN_VERSION`/`IPAM_HTTP_READ_TIMEOUT`/`IPAM_FORCE_HSTS`。
- `install.sh`：生成 `IPAM_METRICS_TOKEN` 并同步给 observability。
- `observability/{prometheus.yml,compose.observability.yaml,README.md}`：令牌抓取接线与说明。
- `docs/manual/operations.md`：「网络安全加固（M6-017）」章节（反代配置、CSP 调整、自检命令）。

## 8. 验证证据

- 单测：`platform`（安全头硬化/BodyLimit/RejectTrace/MetricsAuth/CSP 哈希）、`cmd/control-plane`（引擎级 CSP+TRACE+413、`tlsMinVersion`/`splitList`）。
- 真机（HTTP 8443）：安全头齐全；CSP 中 `sha256-` 与所服务 `index.html` 内联脚本哈希一致；`TRACE→405`；2MB 请求体 `→413`。
- **E2E**：Playwright 14/14 在默认 CSP 下通过（页面与图标正常渲染）。
- TLS（临时 :9443）：`tls1_1` 握手被拒；`tls1_2` 命中 `ECDHE-RSA-AES128-GCM-SHA256`；`tls1_3` 命中 `TLS_AES_128_GCM_SHA256`；TLS 响应含 HSTS。
- `/metrics`：设令牌后无/错令牌 401、正确令牌 200；未设令牌时 200（并告警）。
- `go test ./...`、`golangci-lint run ./...`、`gen-openapi --check`、两套 compose `config` 均通过。

## 9. 边界与后续

- CSP 已在 M6-018 中彻底移除 iconify 公网 CDN 放行（图标离线打包），运行期零外链。
- 限流仍为单实例内存计数；多实例共享限流随 M6-003B。
- `WriteTimeout` 默认关闭：慢客户端写保护依赖反代/连接数限制，单机口径不宣称高可用。
- 容器镜像漏洞扫描（`docker scout` 等）需网络，未纳入自动门禁；手册提供自检命令。
