# M6-018 图标离线化实现说明

> 目标：移除运行期对 iconify 公网 CDN（`api.iconify.design`）的依赖，使内网/离线环境图标完整可用，并让 M6-017 的 CSP 收敛到零外部域。

## 1. 背景

Vben 的 `IconifyIcon`（`@iconify/vue`）按图标名渲染；未在本地集合中的图标会**运行期**请求 `https://api.iconify.design/...`。M6-017 为兼容该行为在 CSP 放行了 iconify CDN，这在离线/内网交付场景下既是可用性问题（断网即缺图标），也是安全弱项（对外连接 + CSP 放行面）。

## 2. 方案：构建期提取离线子集

### 2.1 扫描
`scripts/gen-offline-icons.mjs`：
- 扫描 `web/apps/web-ipam/src` 与 `web/packages`（排除 `node_modules/dist/.turbo` 等）中形如 `prefix:name` 的 iconify 图标 token；
- 用 `@iconify/json/collections.json` 的合法前缀表过滤非图标文本（如权限域 `dhcp:read`、URL `https://`）。

### 2.2 子集提取
- 对每个前缀读取 `@iconify/json/json/<prefix>.json` 完整集合，只保留用到的图标；
- 递归解析 `aliases` 依赖的父图标（如 `alert-triangle` → `triangle-alert`）；
- 保留 `prefix/width/height/info` 元数据，去掉无关内容。

### 2.3 产物
- 生成 `web/apps/web-ipam/src/icons/offline-icons.generated.ts`（`offlineIconCollections: unknown[]`，确定性排序）；
- 当前规模：**8 集合 / 144 图标 / ≈51 KiB**（lucide 126、ion 10、ep 2、mdi 2、其余各 1）。

### 2.4 运行期注册
`web/apps/web-ipam/src/icons/offline.ts`：
```ts
import { addCollection } from '@vben/icons';
for (const c of offlineIconCollections) addCollection(c as IconifyCollection);
```
在 `bootstrap.ts` 顶层副作用导入 `#/icons/offline`，确保任何图标渲染前完成注册；命中本地集合即不再发起网络请求。

## 3. CSP 收敛（M6-017 联动）

`platform.DefaultHTMLCSP`：
- `img-src`：`https://api.iconify.design` → 移除，仅 `'self' data: blob:`；
- `connect-src`：`https://api.iconify.design https://api.simplesvg.com https://api.unisvg.com` → 仅 `'self'`。

`@iconify/vue` 库内部仍含有默认 API host 字符串（惰性兜底代码，不可避免），但已无图标触发取图；即使有遗漏，CSP 也会阻断请求。

## 4. 门禁与工具

- `make gen-icons` / `node scripts/gen-offline-icons.mjs`：再生；
- `make gen-icons-check` / `--check`：与已提交文件比对，不一致非零退出；
- `scripts/make-part.sh`：`build` 前再生、`test` 时校验；
- `scripts/check-webui-offline.sh`：产物须内置离线集合标记（`keyboard-esc`），否则失败；
- CI `web` job：`pnpm install` 后执行 `node ../scripts/gen-offline-icons.mjs --check`；
- E2E 新增「图标离线渲染与零外链」步骤：断言页面有内联 SVG 图标且全程 0 次指向 iconify 域的请求。

## 5. 连带修复

- 发现并修正无效图标 `lucide:speedometer`（lucide 无此图标，必然 404 空白）→ `lucide:gauge`（`views/dns/security/index.vue`）。

## 6. 验证证据

- `node scripts/gen-offline-icons.mjs --check`：一致；
- `bash scripts/check-webui-offline.sh`：PASS（产物零外链资源）；
- `pnpm test`：通过；`vue-tsc --noEmit`：0 error；
- 构建产物：`bootstrap-*.js` 内含离线图标数据；CSP 头不含任何外部域；
- **E2E 15/15**（含新步骤）：图标正常渲染、无 `iconify.design/simplesvg/unisvg` 请求。

## 7. 边界

- 动态拼接的图标名（运行时字符串）无法静态扫描：生成脚本对未命中名告警；此类用法需改为字面量或显式补充；
- 新增图标后须重跑生成器（`build`/`test` 与 CI 已覆盖）；
- `svg:` 前缀为 Vben 本地 SVG（早已离线），不纳入本机制。
