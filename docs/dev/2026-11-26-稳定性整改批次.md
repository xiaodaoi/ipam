# 2026-11-26 稳定性整改批次（M6-052~M6-068）

## 设计对接点

本轮整改不新增业务面能力，目标是消除「装不上 / 重启即失效 / 长期运行静默退化」三类问题。
所有变更保持既有接口契约；仅新增少量内部字段与指标，API spec 无破坏性变更。
