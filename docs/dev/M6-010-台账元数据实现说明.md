# M6-010B3 逐 IP 台账元数据与 CSV 导出实现说明

## 1. 数据模型

迁移 `0034_ledger_meta.sql`：

```sql
ledger_meta(address inet primary key, subnet_id uuid, site, vlan, purpose, "user", phone, remark, custom_attrs jsonb, updated_at)
```

- `address` 为自然键（IPv4），`subnet_id` 可空、随子网删除级联；
- `custom_attrs` 为键值对（资产编号、位置等）；
- `user` 字段避开 SQL 保留字，需加引号。

## 2. 后端

- `LedgerMetaRepo`（PG/内存）：`List(subnetID)`、`Upsert`、`Delete`。
- `LoadLedgerMeta` 全量加载，注入 `LedgerSource.Meta`。
- `QueryLedger` 在组装完地址行后回填 `purpose/phone/remark/site/vlan/customAttrs`；
  `user` 非空时覆盖 `owner`（逐 IP 元数据优先于资产登记）。
- `PUT /ledger/meta`：校验 IPv4 与 VLAN 0–4094，upsert 后返回保存内容。
- 注意：PG `inet` 的 `address::text` 会带 `/32`，查询必须用 `host(address)` 才能与台账行的纯 IP 对齐。

## 3. 前端

- `IpPlanMap` 编辑弹窗新增站点、VLAN 字段，并将 `vlan/site` 纳入 `save` 事件；
- v4 台账页把 `row.purpose/phone/site/vlan/customAttrs/remark` 填入地址格；
- `@save` 从“仅提示”改为调用 `PUT /ledger/meta`（批量选中的每个 IP 一次 upsert），保存后刷新矩阵；
- 页头新增「导出 CSV」：导出当前网段全部地址格（IP/状态/主机名/MAC/使用人/用途/备注/租约起止）。

## 4. 验证

- 单测：`TestQueryLedger_逐IP元数据`（元数据回填与 owner 覆盖）、`TestMemLedgerMetaRepo`（过滤/删除）。
- 真实环境：
  - `PUT /ledger/meta` 保存 10.61.40.20 的用途/使用人/电话/站点/VLAN/自定义属性；
  - `GET /ledger?subnetId=...` 返回对应字段；
  - 清理测试元数据。
- 前端 typecheck/eslint/build、E2E 11/11。

## 5. 边界

- 地址必须为 IPv4；IPv6 台账为子网级汇总，暂无逐地址元数据；
- 元数据不触发 Kea 下发（纯展示/规划信息）；
- CSV 导出为当前网段全量地址格，不含跨网段汇总。
