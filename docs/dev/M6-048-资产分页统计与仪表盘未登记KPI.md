# M6-048 资产服务端分页/统计、pg_trgm 检索与仪表盘未登记 KPI

> 起因：M6-047 之后资产页仍是"全量拉取 + 前端分页/前端算 KPI"，终端规模上千后列表与统计都会变慢且数字随页跳动；同时仪表盘看不到"还有多少终端没登记"，登记率只能靠人工对照两个页面。

## 1. 需求与取舍

| 能力 | 取舍 |
|---|---|
| 服务端分页 | `page/pageSize`（默认 20，上限 200）；`total` 为筛选后总数，与 `items` 解耦 |
| 服务端统计 | `stats` 与 `items` 使用**同一筛选条件**一次返回；KPI 不随翻页跳变，也不额外发请求 |
| 在线筛选 | 在线集合由联动绑定归并得出（`AssetLeaseIndex`），以身份键数组下推到 SQL（`identity/mac/duid ANY(...)`），避免把全部资产拉到内存再过滤 |
| 关键字索引 | `pg_trgm` GIN：owner/dept/mac/duid + `replace(lower(mac),':','')` 表达式索引（支持省略分隔符的 MAC） |
| 仪表盘 KPI | 未登记数复用 `AssetService.Discover`（与发现页完全同口径），登记率 = 已登记/(已登记+未登记) |

## 2. 契约（API 先行）

- `GET /assets` 新增 `page`、`pageSize`、`scope`（all/unassigned/tagged）；
- `AssetList` 新增 `stats: AssetStats`；`total` 明确定义为"筛选后总数（不受分页限制）"；
- 新增 `AssetStats`：`total/assigned/unassigned/owners/depts/online/offline/tagged`；
- `DashboardOverview` 新增 `unregisteredTerminals`、`ignoredTerminals`、`assetTotal`（均可空，资产域不可用时省略）；
- 契约源：`api/openapi/{paths/asset.yaml,components/schemas/{asset,dashboard}.yaml}`，再 `make gen`。

## 3. 后端实现

### 3.1 `AssetQuery` + 双实现

```go
type AssetQuery struct {
    OrgID string; OrgIDs []string   // 服务层把单节点展开为子树 ID 集合
    Q, Scope string                 // all|unassigned|tagged
    Online *bool; OnlineIDs []string // 在线身份键集合（含 DUID 别名）
    Limit, Offset int
}
```

- `PgAssetRepo.List/Stats` 共用 `assetWhere`（组织 `ANY`、关键字 ILIKE + 去分隔符、scope、在线集合），避免"列表与统计条件漂移"；
- `MemAssetRepo` 以 `filtered()` 实现同语义筛选，便于单测与 PoC；
- `Stats` 用单条 SQL 聚合：`count(*) FILTER (...)` 统计 assigned/owners/depts/tagged/online，`Offline=Total-Online`。

### 3.2 仪表盘 KPI

`AssetService.TerminalStats(ctx, bindings)`：

```text
Unregistered = len(Discover(bindings))     // 有效租约 - 已登记 - 忽略
Ignored      = len(忽略名单)
Assets       = len(asset)
```

`dashboard.Service` 新增 `TerminalStatsSource` 注入点，与其它数据源并发取数；失败保持 `nil`（前端显示 —），不拖垮整页。缓存沿用仪表盘 5s TTL。

### 3.3 索引

`db/postgresql/migrations/0053_asset_trgm.sql`：

```sql
CREATE EXTENSION IF NOT EXISTS pg_trgm;
-- owner / dept / mac / duid 的 gin_trgm_ops
-- + replace(lower(mac), ':', '') 表达式索引（省略分隔符搜索）
```

## 4. 前端

- **资产登记**：表格改服务端分页（切页/改每页条数都重新请求）；KPI 卡与表头计数全部取 `stats/total`；筛选（组织/关键字/范围/在线）变更后回到第 1 页；CSV 导出按当前筛选最多取 500 条并提示导出条数；
- **仪表盘**：新增「未登记终端」KPI 卡（值=未登记数，副标题=登记率/已登记/忽略），`ipam-stat-grid--five` 五卡布局（1600/1024/640 断点自适应）；
- zh/en 文案成对。

## 5. 验证

**单测**

- `TestAssetListPaginationAndStats`：25 条资产 + 2 条在线 → 首页 10 条/统计 25；第 3 页 5 条且统计不变；`online=true` 收敛为 2；scope unassigned/tagged 各 12/9；组织子树 + 分页 13 条第 2 页 3 条；
- `TestTerminalStats`：已登记 1、忽略 1、过期 1 → `Unregistered=1, Ignored=1, Assets=1`；
- 既有页面/批量/忽略/租约视图用例全部保持通过。

**真实环境（2026-11-24）**

```text
[migrator] applied 0053_asset_trgm
25 条测试资产：page1=10 total=25 stats{assigned:13,unassigned:12,owners:1,depts:1,online:0,tagged:9}
page3=5 / total=25；unassigned=12；tagged=9；组织子树 page1=5 total=13
GET /dashboard -> unregisteredTerminals 232 = /assets/discovered 232；assetTotal=25、ignored=0
```

E2E：仪表盘断言「未登记终端」卡与登记率文案；「批量登记与忽略名单」步骤新增服务端分页（pageSize=1 两页不同记录、total 恒定）、`stats` 字段、`online=true/false` 过滤断言；**23/23 通过**。

## 6. 遗留

- CSV 导出上限 500 条（受批量登记上限对齐），更大规模应改为异步导出任务；
- 资产页未提供排序（按 identity 固定），如需"最近活跃/在线优先"排序需在契约加 `sort`；
- `pg_trgm` 对超短关键字（<3 字符）仍然退化为扫描，前端可提示"至少输入 3 个字符"；
- 仪表盘 KPI 依赖资产域 + 绑定快照，绑定源异常时未登记数显示 —（不误报 0）。
