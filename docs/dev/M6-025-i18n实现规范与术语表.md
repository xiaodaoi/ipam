# M6-025 前端全量 i18n：实现规范与术语表

> 适用范围：`web/apps/web-ipam/src/{views,components,layouts,api,router}` 中所有**用户可见文案**。
> 目标：默认 `zh-CN` 文案保持不变（E2E 依赖），`en-US` 提供完整英文；运行时可切换语言且无需刷新。

## 1. 文件与命名空间

- 语言目录：`web/apps/web-ipam/src/locales/langs/{zh-CN,en-US}/`
- 一个模块一个文件，文件名即命名空间（`loadLocalesMapFromDir` 按文件名挂载）：

| 文件 | 叶子 key | 覆盖范围 |
|---|---|---|
| `page.json` | 80 | 仅导航（已存在，含 `page.onboarding.*`），勿改 |
| `dhcp.json` | 500 | `views/dhcp/{subnets,options,dualstack,leases,reservations,utilization}`、`subnets/options.ts` |
| `dhcpLedger.json` | 236 | `views/dhcp/ledger/**` |
| `dns.json` | 530 | `views/dns/**` |
| `logs.json` | 382 | `views/logs/**`、`components/log-storage-panel.vue`（`logs.storage.*`） |
| `dashboard.json` | 74 | `views/dashboard/ipam/**`（`dashboard.ipam.*`） |
| `system.json` | 608 | `views/system/**`、`views/_core/about/**`（`system.about.*`、`system.orgs.*`） |
| `shared.json` | 135 | `components/{force-password-change,org-filter-card,org-manage-card,ip-plan-map}`、`layouts/auth.vue` |
| `core.json` | 108 | `views/_core/profile/**`、`views/_core/authentication/login.vue` |

> 未新建 `app.json`：布局与登录页文案分别落入 `shared.json`、`core.json`，避免多一个只放两三条文案的命名空间。

> **不要**新建 `common.json`、`profile.json`、`ui.json`、`preferences.json`、`authentication.json`：
> 这些是 `@vben/locales` 上游命名空间，应用侧同名会覆盖底座文案。

键结构建议 `模块.页面.含义`，例如：

```json
{
  "subnets": {
    "title": "子网管理",
    "create": "新建子网",
    "deleteConfirm": "确定删除子网 {name} 吗？",
    "columns": { "name": "名称", "cidr": "网段" }
  }
}
```

## 2. 代码写法

```vue
<script setup lang="ts">
import { computed } from 'vue';

import { $t } from '#/locales';

// 模块级常量若含文案，必须用 computed（切换语言才会更新）
const statusOptions = computed(() => [
  { label: $t('dhcp.subnets.status.enabled'), value: 'enabled' },
]);
</script>

<template>
  <PageHeader :title="$t('dhcp.subnets.title')" />
  <a-button>{{ $t('shared.actions.save') }}</a-button>
</template>
```

规则：

1. **模板**直接 `$t('ns.key')`，无需 import（全局注入）。
2. **脚本**中用到 `$t` 时 `import { $t } from '#/locales';`。
3. 纯展示数组/对象（表格列、下拉选项、状态映射、Tab 标题）一律包 `computed`；
   仅一次性初始化（如 `Modal.confirm` 调用参数）可直接 `$t(...)`。
4. 插值统一 `{name}` 占位：中文 `共 {n} 条`、英文 `{n} items`；调用 `$t('key', { n })`。
5. 不做复数规则（vue-i18n 无内置复数），英文用 `item(s)` 或直接 `{n} items`。
6. **不要**把以下内容抽成 i18n：
   - 代码注释（中文注释保留）；
   - 与后端契约比较的值/枚举（如 `'enabled'`、`'IPv4'`、`'A'`、`'nxdomain'`）；
   - 日志、`console.*`、`throw new Error` 的技术信息；
   - 纯符号（`—`、`/`、`·`）。
7. 日期/数字格式保持原样（`dayjs(...).format('HH:mm:ss')`），仅中文单位（`天/时/分/台/次`）抽取。
8. **不得改写 zh-CN 文案**：逐字搬移（含全角标点、空格），否则 E2E 与用户习惯都会变。
9. 每个 key 在 zh-CN / en-US 两个文件中**必须同时存在且结构一致**。
10. 不要改动 `web/packages/@vben/**`、`api/gen/**`。

## 7. 语言偏好持久化（重要）

**问题**：上游 `@vben-core/preferences` 的 `initPreferences()` 采用
`merge({}, initialPreferences, cachedPreferences)`，初始化配置（含默认值 `app.locale = 'zh-CN'`）
永远优先，缓存只补齐缺失字段。因此 `updatePreferences({ app: { locale } })` 虽然会写入
`preferences` 缓存，但页面刷新后仍被默认值覆盖，语言回退为中文。

**处理**（不改上游包）：`src/utils/persisted-locale.ts` 提供
`localeStorageKey()` / `parsePersistedLocale()` / `readPersistedLocale()`；`src/main.ts` 在
`initPreferences()` **之前**读取 `preferences-locale`，初始化完成后
`updatePreferences({ app: { locale: persistedLocale } })` 回填。单测见
`src/utils/persisted-locale.test.ts`。

> 注意顺序：`#/locales` 与 `bootstrap` 是 `initPreferences()` 之后动态导入的，读缓存必须放在
> `main.ts` 入口处，否则缓存已被默认值覆盖。

## 8. vxe 表格与语言切换

`useVbenVxeGrid({ gridOptions })` 只在初始化时消费一次配置；语言切换后表头、空态不会自动更新。
约定写法：

```ts
const gridOptions = computed<VxeGridProps>(() => ({
  columns: [{ field: 'name', title: $t('dhcp.options.colName') }],
  emptyText: $t('dhcp.options.empty'),
  loading: loading.value,
  rowConfig: { keyField: 'id' },
}));
const [Grid, gridApi] = useVbenVxeGrid({ gridOptions: gridOptions.value });
// 语言切换后同步列头与空态
watch(gridOptions, (opts) => gridApi.setState(opts as any));
```

`as any` 仅用于抹平 vxe 泛型默认参数差异，项目内已有同类断言；若上游修正 `setState` 签名应移除。

## 9. 新增文案的工作流

1. 在对应模块的 `zh-CN/<ns>.json` 与 `en-US/<ns>.json` **同时**增加 key；
2. 中文值逐字复制原文（含全角标点、占位符两侧空格）；
3. 模板 `$t('ns.key')`；脚本 `import { $t } from '#/locales'`；
4. 展示型常量包 `computed`；
5. 跑 `python3 scripts/check-i18n-keys.py && python3 scripts/check-ui-i18n.py`；
6. 改动页面在 zh/en 各看一遍（或跑 `/tmp/opencode/i18n-switch.mjs`）。
