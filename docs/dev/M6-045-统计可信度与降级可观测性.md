# M6-045 统计可信度与降级可观测性实现说明

> M6-043（日志断流）+ M6-044（租约口径）复盘后的四项加固：降级不丢异常、离线口径与在线对齐、抽样的 KPI 有提示、口径一致性进 E2E。

## 1. 降级抽样保留 WARN/ERROR

**问题**：`Render` 降级时把 `ch_out` 渲染成 `type=sample rate=N`，对整条流均匀抽样，故障日志同样只剩 1/N。

**实现**（`internal/module/logexport/logexport.go`）：

```text
正常：normalize → ch_out(sample rate=1) → clickhouse

降级：normalize → ch_err(filter severity != INFO)          ─┐
                → ch_info(filter severity == INFO) → ch_sample(rate=N) ─┴→ clickhouse
```

- ClickHouse sink 的 `inputs` 在降级时替换为 `["ch_err","ch_sample"]`（Vector 原生扇入）；
- 正常模式仍是单一 `ch_out rate=1`，行为不变；
- `vector validate` 验证通过（真实模板渲染 + 容器内二进制）。

**取舍**：INFO 抽样仍是均匀随机，抽样率 N 越大越小，但错误日志 100% 保留，排障能力有保证。

## 2. 在线租约只认 active 且租期未过

`onlineLeaseSnapshot`（`internal/module/dashboard/service.go`）：

- 只统计 `state == "active"`；`grace` 在台账六态里是「过期/宽限」，单列，不再混入在线；
- `cltt > 0 && valid_lft > 0` 时校验 `cltt + valid_lft > now`，避免绑定状态滞后造成“假在线”；
- 仍要求落在已配置子网内、剔除静态/保留、`0.0.0.0`/`::`；
- 同一快照同时产出归一化 MAC 集合，供离线判定复用（台账只查一次）。

## 3. 离线改为“近 24h 有活动且无租约”

`terminalFlow`：

- 滚动 24h 窗口（不再用「今日 0 点后未见」）；
- 用归一化 MAC（小写、去 `:`/`-`）与在线租约集合比对，排除“日志未刷新但租约仍有效”的设备；
- 台账不可用时回退旧口径（今日未见），页面不白屏；
- 卡片标签改为「近 24h 有活动·无租约（日志）」，明确它不是“当前离线设备数”。

## 4. 抽样状态可见

**契约**：新增 `GET /logs/sampling`（logs 域只读，避免把外发地址等配置暴露给只读角色）：

```json
{ "degraded": false, "ingestSampleRate": 1, "diskUsedPercent": 71.4 }
```

**前端**：`composables/use-log-sampling.ts` 复用于仪表盘与日志概览：

- 降级时顶部黄色提示：日志类 KPI 是 1/N 抽样下界，在线租约/地址池不受影响；
- QPS 卡片 hint 追加「抽样 1/N」；
- 趋势卡副标题追加「抽样 1/N」。

## 5. 口径一致性进 E2E

`tests/e2e/run.mjs` 新增步骤「统计口径一致性（在线租约/池已用）」：

- `onlineNow == onlineV4 + onlineV6`；
- `Σ poolUtilTop.used == onlineNow`（poolTopN=100）；
- 仪表盘 v4/v6 与 `/ledger?family=…&state=online` 一致（容差 2，吸收两次请求间的租约续期）；
- 首个有租约的池，其 `used` 与 `/ledger?subnetId=…&state=online` 一致；
- 仪表盘 UI 断言「在线租约」+ `IPv4 x · IPv6 y` + 「日志口径」。

历史漂移是 49 vs 103，容差 2 仍能拦截同类回归。

## 7. 遗留

- 抽样提示依赖 `/logs/sampling`，接口不可达时静默隐藏（不阻塞页面）；
- 离线数为日志+台账近似（日志缺行时会低估），页面已标注口径；
- 若后续要求“设备数”而非“地址数”，需要引入稳定的设备主键（当前 v4/v6 用不同标识，约 3/280 绑定同时带双栈）。
