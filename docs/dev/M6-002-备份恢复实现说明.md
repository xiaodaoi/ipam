# M6-002 备份恢复实现说明

## 1. 备份内容

一次备份目录（`IPAM_BACKUP_DIR`，默认 `/srv/log-exports/backups/<id>`）：

- `postgres.dump`：`pg_dump --format=custom`；
- `config.tar.gz`：`IPAM_BACKUP_CONFIG_DIRS`（默认 `/etc/unbound-ctl`）；
- `manifest.json`：id/kind/时间/checksum/日志月份/配置目录；
- `clickhouse/logs-YYYY-MM.parquet`：按月日志导出。

ClickHouse 采用既有 `ChAdmin.ExportMonth`（HTTP + Parquet），避免引入备份盘与共享卷权限；恢复时 `TRUNCATE logs`/`logs_topn_hourly` 后逐月 `INSERT ... FORMAT Parquet`。

## 2. 任务模型

`backup_record`（迁移 0029）：

- `status`：running / success / failed / restoring；
- `kind`：manual / auto / pre_upgrade；
- `dir`、`size_bytes`、`checksum`、`months[]`、`error`、`started_at/finished_at`。

`backup_settings`：`enabled`、`schedule_hour(UTC)`、`retention_count`。

创建接口异步：先落 running 记录，goroutine 执行（30 分钟超时），前端 5 秒轮询。

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/system/backups` | 最近 100 份 |
| POST | `/system/backups` | 异步创建 |
| DELETE | `/system/backups/{id}` | 删除记录+文件（进行中拒绝） |
| GET | `/system/backups/{id}/download` | tar.gz 流 |
| POST | `/system/backups/{id}/restore` | `confirm=true`，同步恢复 |
| GET/PUT | `/system/backup-settings` | 自动备份策略 |

全部 system 域权限；恢复为危险操作。

## 4. 运维

- 备份目录与日志归档共用 `ch-exports` 卷；`volume-init` 将卷 owner 改为 10001，control-plane 以 `ipam` 用户运行；
- 升级前建议 `POST /system/backups` 备注 `pre_upgrade` 并下载留存；
- 恢复需维护窗口：PG 连接会短暂中断，恢复成功后刷新页面；
- 保留份数默认 7，超过自动删除最旧（跳过 running/restoring）。

## 5. 已知限制

- ClickHouse 只恢复日志表，不包含系统表/用户/权限；
- 配置包只归档不自动覆盖，避免误覆盖引擎配置；
- 备份未加密；大文件下载无断点续传；
- `pg_restore --clean` 要求目标库无长事务/长连接，需按维护手册执行。
