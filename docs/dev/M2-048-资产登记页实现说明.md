# M2-048 资产登记页实现说明

> 对应任务卡 `docs/pm/board/review/M2-048-资产登记页.md`；架构口径见 §13.4（地址台账页签 / 资产登记以 MAC 为身份键）。

## 1. 交付内容

在「DHCP 服务 → 地址台账」下新增第三个页签「资产登记」，补齐 M2 里程碑出口中的资产登记能力；后端 API（M2-004）此前已就绪，本卡补齐前端消费与两处后端缺陷。

| 层 | 落点 | 说明 |
|---|---|---|
| 页面 | `web/apps/web-ipam/src/views/dhcp/ledger/assets.vue` | 组织树侧栏 + 关键字工具条 + 资产表格 + 登记/编辑弹窗 |
| 路由 | `web/apps/web-ipam/src/router/routes/modules/dhcp.ts` | `DhcpLedgerAssets`（`/dhcp/ledger/assets`，authority `assets:read`） |
| API 客户端 | `web/apps/web-ipam/src/api/ipam.ts` | `listAssets({orgId,q})`、`upsertAsset`、`deleteAsset`、`AssetUpsert` |
| i18n | `web/apps/web-ipam/src/locales/langs/{zh-CN,en-US}/page.json` | `page.dhcp.assets` |
| 权限域 | `internal/module/platform/rbac.go` | `/api/v1/assets` 独立为 `assets` 域 |
| 标签规整 | `internal/module/ipam/asset.go`、`subnet_pg.go` | nil 标签 → 空数组，规避 NOT NULL 违反 |

## 2. 设计对接点

- **页签归属**：沿用地址台账父路由（`ledger/parent.vue` + `RouterView`），把资产登记作为第三个子路由，与 IPv4/IPv6 台账并列，等价于架构要求的「总览矩阵 / 租约明细 / 资产登记」页签模型。
- **身份键语义**：MAC 为唯一键，前端 `normalizeMacInput` 归一化为小写冒号格式；编辑态 MAC 只读，仅可改使用人/部门/组织/标签/备注，体现「换址不丢」。
- **组织关联链**：`orgId` 可选，绑定到组织节点后即形成「终端 → 组织」关联，为日志中心按组织维度过滤（`logquery/pg_expander.go` 读 `asset.mac`）提供数据基础。
- **权限点一致性**：角色管理页暴露 6 个权限域（含 `assets`），本次将 `domainOf` 的 `/assets` 从 `dhcp` 域拆出，「角色可勾选的权限点」与「实际拦截的权限点」恢复一致。

## 3. 关键代码路径

1. 页面加载：`onMounted` → `listOrgTree()` + `listAssets({orgId,q})`。
2. 登记/更新：弹窗 `save()` → `normalizeMacInput` + 校验使用人 → `PUT /assets`（`asset.write` scope）→ `load()` 刷新。
3. 删除：行内 `Popconfirm` → `DELETE /assets/{mac}`（`asset.write`）。
4. 后端写库：`AssetHandler.UpsertAsset` → `AssetService.Upsert`（MAC 归一化 + org 校验 + `normalizeTags`）→ `PgAssetRepo.Upsert`（`ON CONFLICT (mac)` 幂等）。
