## 关键代码路径

1. **游标分页**：`(ts DESC, client_mac DESC, domain DESC)` 全同向排序 ⇒ CH 单一元组比较
   `(ts, client_mac, domain) < (?, ?, ?)`；编码 `{tsMillis}:{mac}:{domain}`（`cursor.go`，
   两实现共享 `beforeCursor`）。DateTime64(3)+双 tiebreaker 使边界歧义率≈0。
2. **CIDR→区间**（`cidr.go`）：v4 先映射 `::ffff/(96+n)` 再求 `[lo,hi]`——直接对 IPv6 列传
   v4 CIDR 会因 IP 版本不匹配被 CH **静默判 0**。多 CIDR 合并重叠段后 `BETWEEN toIPv6`，
   参数原生绑定 `netip.Addr`（16 字节直传，绕开 v4-mapped 文本渲染差异）。
3. **TopN/QPS 口径**：原表聚合（窗内实测远低于 §8 的 3s 预算）。`logs_topn_hourly`
   MV 已随建表预置；切换触发条件=数据量级上升或 DNS 源 IP 提取后口径变宽（记 §6）。
   QPS 因 intervalSec 可变固定走原表 `toStartOfInterval` 分桶。
4. **采集链修复**：logs.sql 的 `client_ip/sip` 改 `Nullable(IPv6)` + vector VRL 空 IP 落
   null（'' 无法解析会整批失败）；ts 用毫秒字符串保证游标精度。unbound 补
   `logfile`/`log-queries`（模板与 BuildConf 五源合成两处同步）。

## 已知限制

DNS 事件目前无源 IP/MAC（vector 解析仅 qname）⇒ 组织维度过滤只命中 DHCP 事件；
组织级 DNS TopN/QPS 待 unbound 查询日志源提取落地后自动生效。
