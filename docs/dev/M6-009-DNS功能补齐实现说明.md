# M6-009A DNS 功能补齐实现说明

## 1. 记录类型

`ValidateRecord` 新增：

- TXT：非空；zonefile 渲染时若无引号自动 `strconv.Quote`；
- SRV：`priority weight port target.`（target 必须 FQDN）；
- MX：`priority exchange.`（exchange 必须 FQDN）。

OpenAPI `DnsRecord.recType` 枚举扩展；前端类型/筛选/统计同步。

## 2. hosts 导入

`POST /dns/hosts/import`：

```json
{ "zoneId": "uuid", "content": "10.0.0.10 app.corp.local app\nfd00::10 v6.corp.local" }
```

- 去除 `#` 注释；字段 `IP name [alias...]`；
- IPv4→A、IPv6→AAAA；TTL 300；
- 同名同类型重复跳过；非法行计入 errors/skipped；
- 创建后触发一次 zone 全量渲染/reload；
- 返回 `{created, skipped, errors[]}`。

前端解析记录页「导入 hosts」弹窗。
