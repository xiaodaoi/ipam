# M6-007 账号体系实现说明

## 1. TOTP

- 密钥：20 字节随机 → Base32（无 padding）；
- 算法：HMAC-SHA1、30s、6 位、±1 窗口；
- 登录：`AuthLoginRequest.totpCode`；启用后缺失 → 401 `TOTP_REQUIRED`，错误 → 401 `TOTP_INVALID`；
- 设置：`/auth/2fa/setup` 保存待确认密钥；`/enable` 验证后置 `totp_enabled=true`；`/disable` 校验口令后清空；
- 前端：登录页动态口令字段；个人中心安全设置生成/启用/关闭；
- 恢复码/备用码暂未实现，认证器丢失需管理员协助（后续）。

## 2. 角色

- `User.roles` 改为字符串数组；账号页多选，选项来自 `/roles`（内置 + 自定义）；
- 后端 `normalizeRoles` 仍按白名单收敛，未知角色丢弃；权限取并集；
- 自定义角色需要先在「角色管理」创建并编译权限。

## 3. 会话

- `POST /auth/logout-all` 提升 `token_version`，所有 access/refresh 令牌立即失效；
- 当前未维护会话表，无法列出单设备/单会话踢出；后续可加 `user_sessions` 与 JTI 绑定。

## 4. 边界

- 007B LDAP/AD 需要目录服务与网络策略，当前环境不可测，保持阻塞；
- TOTP 无恢复码、无防重放缓存（同一 30s 窗口可重复使用）；
- 角色变更会通过 token_version 吊销存量会话（既有逻辑）。
