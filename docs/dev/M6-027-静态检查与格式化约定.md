# M6-027 静态检查与格式化约定

> 适用：`web/` 前端工作区（Vben v5 底座 + `apps/web-ipam`）。
> 目标：任何一次 `make lint` 都能稳定 exit 0，且**可重复执行**（不存在两套规则互相回滚）。

## 1. 门禁流水线（`pnpm run lint` = `vsh lint`）

按执行顺序：

| 顺序 | 工具 | 职责 | 配置文件 |
|---|---|---|---|
| 0 | `golangci-lint run`（根目录，独立于上面这条） | Go 静态检查 | `.golangci.yml` |
| 1 | `stylelint "**/*.{vue,css,less,scss}"` | CSS/SCSS 与 `<style>` 块 | `web/.stylelintrc*`（底座） |
| 2 | `oxfmt --check` | **唯一格式化工具**（TS/TSX/JS/Vue/CSS/JSON/YAML/MD） | `web/oxfmt.config.ts` |
| 3 | `oxlint` | 快速规则检查（正确性为主） | `web/oxlint.config.ts` |
| 4 | `eslint .` | 类型感知规则、import 排序、Vue 语义规则 | `web/eslint.config.mjs` |

`make lint` 封装：`bash scripts/make-part.sh lint`（工具缺失时明确 skip；CI 用 `--strict`）。

## 2. 关键约定

### 2.1 格式化所有权归 oxfmt（D1）

eslint 中以下**排版类**规则已关闭，否则会与 oxfmt 死循环（`eslint --fix` → oxfmt 报错 → `oxfmt` → eslint 再报错）：

- `vue/html-closing-bracket-newline`
- `vue/multiline-html-element-content-newline`
- `unicorn/no-nested-ternary`（要求加括号，oxfmt 会去掉冗余括号）
- `unicorn/number-literal-case`（hex 大小写与 oxfmt 相反）

新增/修改代码后**只跑 `oxfmt`**，不要用 `eslint --fix` 当格式化器。正确顺序：

```bash
cd web && npx oxfmt --threads=2 && rm -f .eslintcache && npx eslint apps/web-ipam/src
```

### 2.2 生成物不参与 lint/格式化（D2）

| 生成物 | 生成方 | 排除方式 |
|---|---|---|
| `apps/web-ipam/src/api/schema.d.ts` | `scripts/gen-openapi.sh`（openapi-typescript） | oxfmt `ignorePatterns` + eslint `ignores` |
| `apps/web-ipam/src/icons/*.generated.ts` | `scripts/gen-offline-icons.mjs` | 同上 |
| `api/gen/**` | `scripts/gen-openapi.sh`（oapi-codegen） | Go 代码，`golangci-lint` 只读检查 |

原因：生成脚本不负责格式化，纳入门禁会导致「`make gen` 后 `make lint` 必红」。

### 2.3 `.d.ts` 模块增强必须保留 `export {}`（D3）

`src/types/user-info.d.ts` 用 `declare module '@vben/types'` 做类型增强。该文件顶部若没有
import/export，TS 会把它当作**全局脚本**，`declare module` 从「增强现有模块」变成
「声明并替换该模块」，症状是满屏 `Module '@vben/types' has no exported member ...`。

因此：

- `**/*.d.ts` 关闭 `unicorn/require-module-specifiers`；
- **禁止对 `.d.ts` 直接执行 `eslint --fix`**（会删掉 `export {}`）。

### 2.4 上游底座遗留（D4）

`pnpm-workspace.yaml` / `package.json` 关闭 `pnpm/yaml-no-unused-catalog-item` 与
`pnpm/json-enforce-catalog`：底座 catalog 保留了 vitepress / naive-ui 等模板与文档站依赖，
清理会牵连上游升级路径，属底座维护范围，不在本产品门禁内追平。

### 2.5 配置位置（D5）

eslint 只保留 `web/eslint.config.mjs` 一个入口。不要新增 `apps/*/eslint.config.mjs`：
应用包内引用 `@vben/eslint-config` 会被 `n/no-extraneous-import` 判为 extraneous 依赖。

## 3. 代码风格连带要求

- 后端返回 204 的接口用 `req<undefined>` / `requestClient.post<undefined>`（`void` 泛型参数会被
  `@typescript-eslint/no-invalid-void-type` 拒绝）；
- 禁止 `!` 非空断言：用 `if (!x) return` 或兜底对象收窄；
- 日期/数字格式化不要写死 `toLocale*('zh-CN')`，直接 `toLocale*()` 随界面语言变化（i18n，见 M6-025 文档）；
- `computed` 内不得写入 `ref`（`vue/no-side-effects-in-computed-properties`）。

## 4. 自查命令

```bash
bash scripts/make-part.sh lint                          # 全量门禁
cd web && pnpm run lint                                 # 仅前端（幂等：连跑两次都应 exit 0）
cd web/apps/web-ipam && pnpm typecheck                  # 类型
cd web/apps/web-ipam && pnpm exec vitest run --dom      # 单测
bash scripts/gen-openapi.sh --check                     # 契约生成物一致
```
