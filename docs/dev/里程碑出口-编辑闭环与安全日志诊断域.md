## 关键代码路径

1. **黑名单两级检查**（`auth_blacklist.go` `Revoked`）：内存命中即时返回（本实例登出零延迟）→ miss 且 db 非 nil 时单行 EXISTS 点查（其他实例登出全局生效）。启动加载（AttachDB）+ Add 双写保证重启恢复；`until > now()` 条件使过期条目天然忽略，无需清理任务。多实例决策记录：PG 点查而非 Redis——控制面量级点查够用、故障域不扩张、零新运维面；refresh token 机制为远期演进（触发条件：真多实例 + 数据面级 QPS）。
2. **lease6 命令链**：`CtrlAgent.Command` 在 args==nil 时**省略 arguments 字段**（`"arguments": null` 会被 Kea 报 `get(string) called on a non-map`）。Lease6List 校验 result∈{0,3} 后投影 `leases` 数组。
3. **DNSSEC 渲染链**：settings PUT → BuildConf 五源合成 → unbound-rendered.conf → checkconf 原子校验（失败保旧=回滚语义）→ reload。测试断言同时锁 `val-permissive-mode: no` 与 `trust-anchor: ". IN DS 20326` 前缀。
4. **view 匹配闭包**（main.go）：`var blRepo` 声明提前使 `policyViewFn` 闭包捕获变量引用（后续赋值 Mem/Pg 对闭包透明）；首中返回 viewName，无匹配/解析失败均静默无提示。
5. **编辑模式类型纪律**：schema 枚举字段（`"B"|"A"|"CUSTOM"` 类）不可由 string 宽化赋值——form 一律显式泛型 `ref<{...枚举联合...}>`；调用点传 schema 引用类型而非手写内联（diagnoseDns 违例已修正）。

## 事故与教训（工程纪律沉淀）

1. **ENOSPC 二次满盘**：bash 工具自身失败（临时文件写不进）时，改用 **tmux 会话执行清理**（输出走内存，`capture-pane` 回收）——`journalctl --vacuum-size` + `/tmp` 清理恢复 54G。**绝不** `docker system prune --volumes`（会删数据卷）。
2. **python 锚点陷阱系列**：anchor 段尾可能有探索时 sed 截断未见的残留行（spec type 段 `description` 在 enum 后）→ 悬空成 YAML 重复键；单行 import 块用 `} from` 锚点切断前缀；多行函数（`=>\n req(...)`）与多行 HTML 标签中间插入行会切断结构——**replace 前必须看完整段/完整标签**，失败分段独立落盘。
3. **镜像重建确认**：`docker compose build` 输出空行 ≠ 重建成功（缓存/静默）——Go 代码改动后必须 `grep Built` 再部署，否则 e2e 验证的是旧二进制（M2-030 trust-anchor 首验假阴性根因）。
4. **e2e 前置语义**：黑名单检查在 JWT 验签之后——测吊销路径必须用合法签名 token + DB 直插 hash，伪造 token 活不到 Revoked。
5. **vue-tsc 与 vite 的检查面差异**：模板结构错误（Invalid end tag）vue-tsc 可能放行而 vite build 拦截——build 错误需看完整输出，grep 过滤会掩盖。
