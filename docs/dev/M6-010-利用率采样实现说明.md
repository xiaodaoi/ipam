# M6-010B1 子网利用率采样实现说明

## 1. 数据模型

迁移 `0033_subnet_utilization.sql`：

```sql
subnet_utilization(id, subnet_id, ts, used, capacity, pct)
```

- `subnet_id` 外键关联 `subnet`，保留 90 天；
- 索引 `(subnet_id, ts desc)` 与 `(ts)`。

## 2. 计算口径

`utilization.Compute`：

1. 仅 IPv4 子网、仅地址池（pool）范围；
2. 容量 = 各池地址数量之和（含首尾）；
3. 已用 = coherence 绑定 IPv4 + 预留 IPv4，落在该子网任一池内，按 IP 去重；
4. 池外静态/保留不计入（避免容量分母与分子口径错位）；
5. pct = used / capacity × 100，上限 100。

## 3. 采样循环

- main 启动 `utilSvc.Run`：立即采一次，之后每 5 分钟（`IPAM_UTIL_SAMPLE_INTERVAL`，最小 1 分钟）。
- 写库后按 90 天清理；失败仅记录日志，不影响控制面。
- 数据源：`subnet` 列表、`reservation`、`coherence_binding`。

## 4. 查询与页面

- `GET /dhcp/utilization`：`DISTINCT ON (subnet_id)` 最新快照；
- `GET /dhcp/utilization/{subnetId}?hours=`：时间窗序列（1–720 小时）；
- 页面：DHCP 服务 → 利用率分析；`TrendChart` 渲染百分比曲线。

## 5. 指标与告警

`/metrics`：

```
ipam_subnet_utilization_percent{subnet_id="...",subnet="...",cidr="..."} 42.50
```

`observability/alerts.yml`：

- `IpamSubnetUtilizationHigh`：>85%，15m，warning；
- `IpamSubnetUtilizationCritical`：>95%，5m，critical。

## 6. 验证

- 单测：容量/去重/池外排除、MemRepo latest/series/prune；
- 真实环境：迁移 0033 应用；latest 返回各子网快照；series 返回多个采样点；`/metrics` 可见指标；
- E2E：`/dhcp/utilization` 页面加载通过。

## 7. 边界

- 采样为 5 分钟粒度，不记录瞬时峰值；如需更细粒度需调整间隔与保留策略；
- 仅 IPv4 池；IPv6 地址空间巨大，百分比意义有限；
- 已用口径来自绑定/预留，不含“在线但未登记”的终端（该口径在仪表盘 TopN 使用日志 distinct IP）。
