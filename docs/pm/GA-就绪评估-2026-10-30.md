## 3. 明确未完成 / 阻塞

| 项 | 原因 | 解锁条件 |
|---|---|---|
| 双机 HA（003B） | 单机无法实现 VIP/Kea hot-standby | 2 台独立主机/VM（不同电源/网络故障域） |
| LDAP/AD（007B） | 无目录服务可测 | LDAP/AD 测试实例 + 网络策略 |
| Helm（012B） | 无 K8s 集群 | K8s 1.28+ 集群、hostNetwork/存储类 |
| RA / option82 选池 / 冲突探测 | 需 IPv6 路由通告/中继/RAW 探测环境 | 对应网络实验环境 |
| DoT 真生效 | 当前仅存 protocol 字段；出网 853 被限制 | 可达 DoT 上游或本地 DoT 测试服务 |
| 泛域名/AXFR/提示页/时段/内置库 | 未排期 | 单独立项 |
| GitHub CI 实跑/镜像签名 | 本环境无 GitHub runner/发布权限 | 推送后观察 + 首次 tag 发布 |

## 4. 交付建议

1. **可交付范围**：单机 DDI（IPAM/DHCP/DNS/日志/审计/备份/License/监控/租约/利用率/发现），面向 5000 终端以内内网。
2. **交付前必做**：
   - 替换自签证书为企业 CA；
   - 设置 `IPAM_JWT_SECRET`、PG 口令、Grafana 口令；
   - 开启「强制首次改密」与 TOTP（按客户策略）；
   - 配置真实上游 DNS、NTP、告警通道；
   - 执行一次备份→恢复演练并记录 RTO；
   - 跑 `bash scripts/install-systemd.sh` 启用自启/看门狗。
3. **不建议承诺**：宿主整机故障自动接管、跨站点双活、LDAP 单点登录（当前版本）。
4. **后续里程碑**：优先 003B（HA）与 007B（LDAP），其次 012B（Helm）与 010B5（RA/冲突）。

## 5. 复现验证命令

```bash
# 后端
go test ./... && go vet ./... && golangci-lint run ./...

# 契约
bash scripts/gen-openapi.sh --check

# 前端
cd web && pnpm test && pnpm --filter @vben/web-ipam run typecheck && pnpm run build:ipam

# E2E（控制面已启动）
PLAYWRIGHT_CHROMIUM=<chromium> IPAM_E2E_BASE_URL=http://127.0.0.1:8443 node tests/e2e/run.mjs

# 压测（隔离环境）
IPAM_RATE_LIMIT=0 go run ./tests/load -base http://127.0.0.1:8443 -path /api/v1/subnets
```
