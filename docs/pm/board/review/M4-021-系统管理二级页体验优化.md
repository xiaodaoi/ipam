## 目标

统一优化系统管理下的 4 个二级页，保持与 M4-015~M4-020 已优化页面一致的视觉与交互语言：

- 账号管理 `/system/users`（原「用户与角色」，与角色管理重名，改名）
- 角色管理 `/system/roles`
- 系统设置 `/system/settings`
- 关于平台 `/system/about`

统一采用 `PageHeader` + 4 张 KPI `StatCard` + `ipam-toolbar` / `ipam-filter-grid` + 统一表格与空状态，浅色/深色自适应，1280/1600 无页面级横向滚动。

复用既有端点：`/users`、`/roles`、`/system/webui-settings`、`/system/restart`、`/system/info`、`/system/metrics`、`/system/log-settings`、`/system/log-archives*`。**本次无 API 契约变更**（`/system/info`、`/system/metrics` 已在 spec 中，仅补前端类型导出与调用封装）。
