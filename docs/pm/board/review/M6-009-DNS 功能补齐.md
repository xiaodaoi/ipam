## 009A 已完成

- 解析记录类型新增 **TXT / SRV / MX**（校验 + zonefile 渲染 + 前端类型筛选/徽标）；
- **hosts 导入**：`POST /dns/hosts/import`（zoneId + content），解析 `IP name [alias...]`，自动创建 A/AAAA（TTL 300），重复跳过，返回 created/skipped/errors；
- 前端解析记录页新增「导入 hosts」弹窗，导入后自动重渲染 zonefile；
- 单测覆盖新类型校验、TXT 引号渲染、hosts 解析/跳过/记录落库。

## 009B1 已完成：rebind protection 内网域白名单

- 渲染 unbound 配置时为所有条件转发域与本地权威域生成 `private-domain`；
- 避免 unbound 默认 rebind protection 把内网 DNS 返回的 RFC1918 地址判为攻击；
- `unbound-checkconf` 校验通过，现有内网解析（smoke.corp.local）不受影响；
- 单测覆盖 `BuildConf` 的 private-domain 输出。

## 009B2 已完成（2026-11-04）

- **泛域名**：记录名校验（仅最左 `*`）+ 前端提示；渲染层实测 `local-data` 不展开通配，
  含 `*` 的区域改走 `auth-zone + zonefile`（`RenderZonefile`），区顶点/显式记录/多级子域行为符合 RFC 1034。
- **DoT**：Upstream 增 `tlsName`，渲染 `forward-tls-upstream: yes` 与 `ip@853#sni`；
  dot/udp 混用只取 dot，避免明文回落。
- **Secondary/AXFR**：区域 `kind=secondary` + `primary`，渲染 `auth-zone`（primary/fallback/for-downstream/for-upstream），不写 local-data。
- **提示页**：`blockPageIP/Title/Message` 设置 + 免认证 `GET /blocked`；redirect 条目指向提示页 IP，设置变更自动重放。
- **策略时段**：`Schedule{days,start,end}`（跨零点/星期/空=全天），`Reconcile` 每分钟收敛，窗口外撤销。
- **名单运营**：CSV 导入/导出、版本快照与回滚（订阅同步/导入前自动快照）、5 类内置分类库一键安装。
- **契约/迁移**：M6-023 spec + 迁移 `0040_dns_ext.sql`（含修复记录类型 CHECK）、`0041_blocklist_version.sql`。

> 关键修正：unbound 1.26 的 `local-data` 不支持 `*.name` 展开。通配 redirect 改用
> `local-zone redirect` + 区顶点 A；普通通配记录改用 auth-zone zonefile。详见实现说明。
