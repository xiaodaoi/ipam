## 目标

在既有操作审计（变更请求/登录/登出、180 天保留、CSV 导出）基础上补齐可取证能力：

1. 记录脱敏后的请求体（变更内容），密码/令牌/密钥/License 等字段自动打码；
2. 每条审计写入 SHA256 链哈希（prevHash + chainHash），可检测单条篡改与断链；
3. 提供完整性校验接口与前端按钮；
4. 明细抽屉展示脱敏请求体与链哈希；
5. 保留策略维持 180 天（M5-032 已内置惰性清理）。

## 验收标准

- [x] 审计写入自动捕获 JSON 请求体（≤8KB），不改变 handler 读取；
- [x] 敏感键（password/token/secret/license/private/authorization/cookie）替换为 `***`；
- [x] PG 写入使用 advisory lock 串行化链哈希，`prev_hash/chain_hash` 入库；
- [x] `GET /audits/verify?from&to` 重算并校验单条哈希与相邻链接，返回 checked/valid/brokenId；
- [x] 审计页“完整性校验”按钮显示结果（链完整 N 条 / 链异常 ID）；
- [x] 详情抽屉展示脱敏请求体、链哈希；
- [x] 历史（迁移前）记录不参与校验，界面明确提示；
- [x] 单测覆盖链校验/篡改检测/脱敏/请求体恢复；
- [x] `go test`、`vue-tsc`/eslint/build、gen-check 通过。

## 设计取舍

- 通用中间件无法无侵入获取“变更前实体”，本卡记录的是**变更后请求体**（脱敏）；实体级 before/after 快照后续按域补；
- 链哈希用于发现篡改，不是 WORM 存储；拥有数据库超级权限仍可重算整条链，生产需配合只读账号/备份/外部日志；
- 历史记录无链哈希，校验从 0030 迁移后的新记录开始。
