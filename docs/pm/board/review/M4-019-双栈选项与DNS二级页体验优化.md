## 目标

在不改动后端契约的前提下，统一优化 8 个页面：

- DHCP：双栈管理（`/dhcp/dualstack`）、选项与类匹配（`/dhcp/options`）
- DNS：上游服务器（`/dns-service/upstreams`）、条件转发（`/dns-service/forward`）、解析记录（`/dns-service/records`）、缓存与性能（`/dns-service/cache`）、安全与诊断（`/dns-service/security`）、封禁管控（`/dns-service/blocklist`）

统一采用 `PageHeader` + KPI 指标卡 + 摘要条 + `ipam-toolbar` + 统一表格/空状态/深色主题，
并补齐搜索、状态筛选、关键状态可视化（健康、冲突、启用率、RTT、同步）与更清晰的信息层级。
