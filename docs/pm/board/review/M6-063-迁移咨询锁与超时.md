## 目标
- 迁移器启动先取 `pg_advisory_lock`，避免多副本/首装并发 DDL。
- 每个迁移文件设置 `statement_timeout=30m`、`lock_timeout=60s`，失败快速返回。
- PostgreSQL 健康检查强制 TCP（`-h 127.0.0.1`），避开 initdb 临时实例的 socket 假就绪。

## 改动范围
- `internal/pkg/migrator/migrator.go`、`deploy/compose/compose.yaml`

## 验证
`go build ./...`、`go test ./...`、`docker compose config -q`。

## 遗留
首装并发场景需在空库 + 慢 initdb 环境验证。
