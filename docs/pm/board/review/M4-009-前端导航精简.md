## 目标

清理 Vben 底座自带的非业务入口，使主导航与个人中心只保留 IPAM 产品实际功能：

1. 移除左侧「演示（Demos）」与「项目（VbenProject/vben-admin）」两个菜单及其页面内容。
2. 将「关于」页面从顶层菜单迁入「系统管理」，作为二级菜单。
3. 移除右上角个人中心下拉中的「文档 / GitHub / 问题&帮助」三项，仅保留「个人中心」。
