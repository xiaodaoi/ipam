## 目标

新部署交付后，管理员第一次登录时能按最短路径完成「组织 → 子网 → DNS 上游 → 区域/记录 → 账号安全」五项最小配置，
并清楚知道还差什么。向导只做只读检测，不替代各页面既有表单，也不引入服务端偏好表。

## 验收标准（可测）

- [x] 仪表盘在未完成/未忽略时显示向导入口 banner，可「继续配置」或「稍后再说」；
- [x] `/onboarding` 展示 5 个步骤，每步显示完成状态（Tag）、检测摘要、跳转按钮与说明；
- [x] 进度条按实际已完成步骤数实时派生（5/5 时可「完成向导」）；

- [x] 完成后或忽略后 banner 不再出现；向导页仍可进入并「重新显示向导」；
- [x] 无权限/接口失败时该步骤显示「检测失败」，不阻塞其他步骤；
- [x] `vue-tsc`、eslint、`pnpm build:ipam` 通过；E2E 覆盖入口→5 步→忽略收起。

## 设计要点

- **状态存储**：`localStorage` 键 `ipam.onboarding.v1.<username>`，与账号隔离；只存 `completed/dismissed/updatedAt`。
  换设备/清缓存会重新提示——单机交付场景可接受，且避免新增偏好表迁移。
- **进度派生**：不落库，每次进入页面重新检测（只读 API），避免状态与真实配置漂移。
- **不强制改密**：第 5 步按「已无待改密」或「已启用 2FA」判定，尊重系统设置里「强制首次改密」开关（默认关闭）。
- **入口可恢复**：忽略不是永久关闭，向导页「重新显示向导」可复位并重新检测。
