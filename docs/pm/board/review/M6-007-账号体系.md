## 007A 已完成

- **TOTP 双因素认证**：
  - `POST /auth/2fa/setup` 生成密钥与 otpauth URI；
  - `POST /auth/2fa/enable` 校验 6 位口令后启用；
  - `POST /auth/2fa/disable` 校验当前口令后关闭；
  - 登录请求支持 `totpCode`，启用后缺失/错误分别返回 `TOTP_REQUIRED`/`TOTP_INVALID`；
  - 登录页新增动态口令输入（未启用可留空）；个人中心「安全设置」启用/关闭。
- **自定义角色赋值**：
  - `User.roles` 契约从 enum 改为字符串数组；
  - 账号创建/编辑改为多选，加载内置+自定义角色；
  - 后端沿用 `normalizeRoles` 白名单（内置 + roles 表）。
- **会话控制**：
  - `POST /auth/logout-all` 提升 token_version，全部设备立即失效；
  - 个人中心提供「注销全部会话」二次确认。
- **审计**：TOTP 启用/关闭/注销全部写入审计动作。

## 007B LDAP/AD（已完成）

- **设置**：`0035_ldap.sql` 新增 `users.auth_source` 与 `ldap_settings` 单行表；`GET/PUT /system/ldap`；
- **认证**：go-ldap 服务账号搜索 → 用户 DN bind → 组成员读取 → 组映射角色；口令实时校验不缓存；
- **影子账号**：目录账号首次登录自动创建（`authSource=ldap`），显示名/角色变化时同步并吊销旧会话；
- **测试**：`POST /system/ldap/test` 真实 bind，返回组与映射角色；
- **降级**：目录不可达 503 `LDAP_UNAVAILABLE`，本地账号不受影响；未启用不暴露状态；
- **安全**：空口令一律拒绝；目录账号禁止本地改密/重置口令；
- **前端**：系统管理 → 目录服务页（连接配置/组映射/连通性测试）；账号页标记目录账号；
- **RBAC 同批修复**：`/system/*` 归 system 域、PUT 计入写方法（此前可被只读用户修改系统设置）。
