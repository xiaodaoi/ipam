## 方案

Revoked 两级检查（db 非 nil 时）：
1. 本地内存——本实例登出的令牌立即生效，免 DB 往返
2. miss → PG 点查 `EXISTS (... WHERE token_hash=$1 AND until > now())`——其他实例登出的令牌全局立即生效
- DB 查询失败吞错返回 false：fail-open 窗口内后续 users 查询与业务写同处 PG 故障域必然失败，等效 fail-closed
- 纯内存模式（db=nil，测试/降级）语义不变
