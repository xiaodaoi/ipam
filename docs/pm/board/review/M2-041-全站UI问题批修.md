### 2026-08-31 · 会话3（第三次报障——真根因实锤：静态资源无缓存头）
- **现象**：orgs 新建根组织仍失败；实测后端 `POST /orgs` 返回 201 正常，部署产物含最新修复逻辑（v-model 绑定 + onConfirm + createOrg 均在）。
- **真根因**：Go 静态服务 `serveStatic` **未发送任何缓存头**（无 Cache-Control/ETag/Last-Modified）→ 浏览器启发式缓存旧 `index.html` → 持续加载旧 chunk URL（旧 orgs 代码），**我们每次部署的修复根本没被加载**。这解释了三次报障「还是不行」。
- **修复**：① `serveStatic` 缓存策略——`index.html` → `Cache-Control: no-cache`（每次回源拿新 chunk 清单）；哈希资产 → `public, max-age=31536000, immutable`（内容寻址天然安全）；② orgs `confirmName` 空名加 `message.warning('请输入组织名称')`（防静默失败 + 诊断可见性）。
- **验证**：`curl -I /` → `Cache-Control: no-cache`；`curl -I /jse/*.js` → immutable；新 bundle orgs chunk 含「请输入组织名称」；`POST /orgs` 201；测试组织清理完毕。
- **用户动作**：**需强刷一次**（Ctrl+F5）清除浏览器已缓存的旧 index.html；此后 no-cache 保证每次部署自动生效。
