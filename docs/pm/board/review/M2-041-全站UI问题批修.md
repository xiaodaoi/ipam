### 2026-08-31 · 会话3（第三次报障——真根因实锤：静态资源无缓存头）
- **现象**：orgs 新建根组织仍失败；实测后端 `POST /orgs` 返回 201 正常，部署产物含最新修复逻辑（v-model 绑定 + onConfirm + createOrg 均在）。
- **真根因**：Go 静态服务 `serveStatic` **未发送任何缓存头**（无 Cache-Control/ETag/Last-Modified）→ 浏览器启发式缓存旧 `index.html` → 持续加载旧 chunk URL（旧 orgs 代码），**我们每次部署的修复根本没被加载**。这解释了三次报障「还是不行」。
- **修复**：① `serveStatic` 缓存策略——`index.html` → `Cache-Control: no-cache`（每次回源拿新 chunk 清单）；哈希资产 → `public, max-age=31536000, immutable`（内容寻址天然安全）；② orgs `confirmName` 空名加 `message.warning('请输入组织名称')`（防静默失败 + 诊断可见性）。
- **验证**：`curl -I /` → `Cache-Control: no-cache`；`curl -I /jse/*.js` → immutable；新 bundle orgs chunk 含「请输入组织名称」；`POST /orgs` 201；测试组织清理完毕。
- **用户动作**：**需强刷一次**（Ctrl+F5）清除浏览器已缓存的旧 index.html；此后 no-cache 保证每次部署自动生效。

### 2026-08-31 · 会话4（最终根因：orgs 页漏 import Input，v-model 断链）
- **现象（关键诊断）**：用户已输入名称仍提示「请输入组织名称」——证明 `confirmName` 被调用但 `nameInput` 为空，**v-model 没写进 ref**；且输入框「不明显」。
- **最终根因**：orgs 页 antd import 是 `{ Button, Card, Tree, message }`——**漏了 `Input`**。无全局 antd 注册（bootstrap.ts 仅 router+MotionPlugin）→ `resolveComponent('Input')` 解析失败 → Vue 渲染成**原生 `<input>`**（不触发 `update:value`）→ 输入不进 `nameInput` → 空名警告；原生 input 无 antd 样式故「不明显」。
- **举一反三**：全站正则扫描「模板用了但 antd import 缺」→ 命中 2 页：`system/orgs` + `dhcp/ledger`（绑定 MAC 输入框同类 bug）→ 均补 `Input` import。
- **UI 优化（用户要求）**：orgs 弹窗输入框改为「组织名称」label + `autofocus` + flex-1 加宽 + 「请输入组织名称」placeholder。
- **验证**：typecheck 0 + build ✓ 8.36s + 零外链 PASS + 容器重建 + 新 orgs chunk 含 `onUpdate:value` 绑定与 label。

### 2026-08-31 · 会话5（创建成功后报「未知 API 路由」——listOrgTree 调错端点）
- **现象**：v-model 修通后，点确定报「未知 API 路由」。
- **根因**：spec 中树端点是 `GET /orgs`（operationId listOrgTree），后端路由亦只注册 `/orgs`；前端 `listOrgTree()` 却调 `GET /orgs/tree`（404）——从 M2-001 起就调错，**组织树从未加载成功**（orgs 页一直空树；ledger/subnets 的组织筛选连带损坏）。创建本身 201 成功，但随后的 `load()` 抛 404 被 catch 显示。
- **修复**：`listOrgTree` → `req('/orgs')`（spec 为准）；同步修正 Go handler 过时注释。
- **验证**：typecheck 0 + build ✓ + 容器重建 + 全流程实测：`POST /orgs`=201 → `GET /orgs` 树含新根；部署 chunk 仅含 `/orgs`、`/orgs/${id}`，无 `/orgs/tree`。
