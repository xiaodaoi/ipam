## 方案（token_version 机制）

- users 加 token_version int（默认 1）；JWT claims 加 ver（签发时取用户当前版本）
- 中间件（RBAC 扩展为认证+授权一体）：解析 claims → 查用户 → **!ok/!Enabled/claims.ver != 用户 ver → 401 TOKEN_REVOKED**
- 吊销触发：改密码/停用/角色变更 → token_version+1 → 存量令牌立即失效（GetByUsername !ok 兜底删除场景）
- 升级兼容：存量令牌无 ver（=0）视为 1（平滑升级，旧令牌不失效）
