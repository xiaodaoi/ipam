## 实施记录

### 2026-08-27 · 会话1
- **JWT**：auth_jwt.go 标准库手搓 HS256（header 校验/验签 hmac.Equal/过期），claims sub/uid/roles/typ/exp；IPAM_JWT_SECRET 环境可配（缺省回落 POC_SECRET→dev 值）。
- **RBAC 雏形**：roles admin/user，HasRole admin 蕴含 user；typ=user/bot 供 §12.3。
- **审计接通**：JWTActorProvider（gin 侧适配 + FromHeader 纯函数便于桩测）；无效令牌回退 system 不阻断业务；token_sub=jwt:sub#指纹前8位（不存原始令牌）。
- **验证**：POST /orgs 201 后 PG 实录 `human|admin|jwt:admin#f4d6a88|create|/orgs|201`；登录序列全 200。
- **遗留**：① 端点级 scope 强制（现在仅记录不拦截）待 RBAC 中间件卡；② Bot Token 独立发放/撤销管理界面 P1；③ 多用户/账号管理界面 P1。
