## 目标
- Kea 配置目录改为命名卷（可写），容器启动时从只读模板播种，`config-write` 可落盘。
- `config-write` 失败记录日志（不再静默丢弃）。
- 控制面每 60s 全量 converge 一次并串行化下发，Kea 单独重启后自动恢复线上子网/预留。

## 改动范围
- `deploy/compose/compose.yaml`、`cmd/control-plane/main.go`

## 验证
`go build ./...`、`go test ./...`、`docker compose config -q`。

## 遗留
`kea-conf4/6` 命名卷首次播种仍来自演示配置，控制面数秒内覆盖；真实 Kea 重启恢复需 staging 验证。
