## 目标

在不改动后端契约（`GET /subnets`、`GET /orgs/tree`、`GET /ledger`、`GET /dhcp/leases6`）的前提下，重构
「DHCP → 子网管理」页的信息架构与视觉：IPv4/IPv6 从「同表混排」改为「族切换 + 族专属摘要」，组织从
「下拉框选择」改为「树形下钻面板」，并补齐容量、利用率、在线租约、Kea 下发覆盖等运营数据。

## 验收标准（可测）

- [x] IPv4 / IPv6 不再同表混排：顶部双族切换卡（子网数 / 在线数 / 已下发数）+ 族专属摘要条 + 单表格按族切换；族与组织状态写入 URL query（`?family=6&org=<id>`）可分享/刷新保持。
- [x] 组织架构面板：搜索、全部组织、节点子网数与在线数徽标（含全部子孙汇总）、当前范围面包屑、点选下钻与再次点击取消、下钻只过滤不重新请求（切换无闪烁）。

## 实施记录（追加式，勿删旧条目）

### 2026-10-28 · 会话1

- **做了什么**：重写子网管理页信息架构，从「族下拉筛选 + 单表混排 + 组织下拉框」改为「双族切换卡 + 族摘要条 + 组织树下钻 + 6 列精简表」。
- **页面骨架**（`views/dhcp/subnets/index.vue`）：
  - `PageHeader` + 4 张 `StatCard`（IPv4 子网 / IPv6 子网 / 在线租约 / Kea 下发覆盖），在线数由 `GET /ledger?state=online` 按 `subnetId` 聚合（v4+v6 各翻页拉全量，不再只取首 100 条）。
  - 左侧组织树面板（`Card` + `Tree`）：搜索（命中即自动展开全树）、`全部组织`、节点徽标「子网数 / 在线数」（自底向上汇总子孙）、底部范围提示；`管理` 按钮打开 `useVbenDrawer` 承载 `org-manage-card.vue`，`onClosed` 重新拉取。
  - 双族切换卡：`IPv4 逐地址规划` / `IPv6 前缀·PD 委派`，显示子网数/在线数/已下发数，选中态渐变 + 对勾；切换写入 `?family=6`，组织写入 `?org=<id>`。
  - 族摘要条：v4 为「子网 / 动态池 / 地址容量 / 平均利用率 / 在线租约 / Kea 已下发」，v6 换成「PD 委派池 / 动态地址池 / 可分配容量」。
  - 表格精简为 6 列（子网 / 所属组织 / 地址池·委派 / 容量 / 在线·利用率 / 操作），把 Kea subnet-id 与租约时长并入「子网」单元格，消除窄屏横向溢出；组织列显示完整路径（`大区本部 › 信息公司`）。
  - IPv6 页签追加「DHCPv6 实时租约」区（`GET /dhcp/leases6`，NA/PD 计数 + 提示与台账在线数的秒级差异）。
  - 原新建/编辑表单弹窗保留并整理（组织、名称、CIDR、租约、地址池/PD、网关 DNS、DHCP 选项）。
- **容量/利用率算法**：`ipv4ToInt` / `ipv6ToBigInt`（含 `::` 展开与非法组判定）→ `capacityOfPool`（pd 走 `2^(delegated-prefix)`，动态池走区间长度）→ `subnetCapacity` 汇总 → `utilizationOf` 用 `used*10000/capacity` 取两位小数，PD-only 子网返回 `null` 显示 `—`；`fmtBig` 输出 K/M/B。
- **样式**（`styles/index.css`）：新增 M4-017 段约 480 行（布局/组织树/族切换卡/摘要条/子网单元格/容量/利用率/操作组），补充 `ipam-chip` 的 blue/cyan/violet/muted 与 `ipam-progress` 的 green/amber/red 色调；全部走 Vben 主题变量。
- **窄屏修复**：≤1400px 组织面板改为全宽置顶（卡体 `max-height:300px` 滚动）并 `align-items:stretch`（原 `flex-start` 在 column 方向会让子项按内容撑宽，导致 820px 下页面级横向溢出 916px）；`.ipam-subnets-main` 及其卡体 `min-width:0 / max-width:100%`，`vxe` 根节点限宽，溢出只在 `.vxe-table--body-inner-wrapper` 内部滚动；族切换卡改 `auto-fit minmax(238px,1fr)` 自适应列数。
- **组件修复**：`org-manage-card.vue` 的 ant-design-vue `Tree` 用了 `#titleRender`（v4 已废弃、不生效），改为 `#title="node"`（插槽参数是合并后的节点数据，非 `{node}` 包裹），修复抽屉内节点渲染与 `node.org` 读取报错。
- **构建**：`vite.config.ts` 为 web-ipam 单独设 `build.target: 'es2020'`——IPv6 容量需 BigInt 精确计算（2^128），默认 es2015 目标会对 BigInt 字面量报 `TOLERATED_TRANSFORM` 降级警告；es2020 目标下构建零警告。
- **验证**：`vue-tsc` 0 error；eslint / stylelint 0 issue；`pnpm --filter @vben/web-ipam build` 成功（41.8s，无降级警告）；Playwright 实测 1920/1600/1280/820 四档、深色主题、IPv6 页签、组织下钻（信息公司 → 1 v4 / 1 v6，范围提示正确）、空组织（经营策划部 → 空表提示）、组织管理抽屉均正常；820px 实测 `documentElement.scrollWidth === clientWidth === 820`。
