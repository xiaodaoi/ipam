## 根因（实锤）

M2-033 的封禁机制是**运行时 local_zone static 注入**（`unbound-control local_zone <name> static`，unbound 1.26 的 RPZ auth-zone 路线不可用），**编译（Compile）需要手动触发**（UI「编译」按钮 / API）。用户加完条目后未点编译 → 运行时态无 local_zone → 解析仍通。手动编译后 dig 复验已 NXDOMAIN。

## 方案（闭环自动化）

AddBlocklistEntry / DeleteBlocklistEntry / SyncBlocklist / CreatePolicyGroup 成功后自动调 svc.ReplayAll（全量重编译所有策略组的 local_zone），用户加完条目即生效，无需手动点编译。
