## 修复清单

1. **实时流「重连中」**：openLogTail 原生 EventSource 无法携带 Authorization → RBAC 401 → onError 重连循环。重写为 **fetch + ReadableStream 流式解析 SSE**（带 token，AbortController 可中断，`{close()}` 接口兼容）
2. **解析记录「无法添加」**：addRecord 校验失败静默 return（zone 未选时点击无反应）→ **明确 message.warning 提示**
3. **组织管理「根组织无效」**：后端实测正常（parentId=null → 201）——根因是前端 window.prompt 交互，归 M2-034 modal 化根治
4. **日志列扩展**：search 页加**应答码（rcode）+ 应答服务器（sip）**列（应答记录可观测）
5. **缓存和性能无数据**：cache 页只有 TTL 配置无性能区（QPS API 实测有数据但前端未消费）→ 加**性能统计区**（近 1h 查询/24h 总查询/小时峰值，getLogQps 消费）
6. **黑名单封禁闭环**（独立批次，commit 45a028f）：RPZ 路线在容器 unbound 1.26 编译下不可用（auth-zone 内 rpz: yes 实测 unknown keyword）→ **local_zone static 拦截方案**（Compile 下发 local_zone 命令 + ReplayAll 启动重放 + 失败上报 + 双向 e2e 决定性）
