## 目标

关闭“不能安全交付”的阻断项，建立可复用的安全默认值：

1. 控制面支持 HTTPS（内置 TLS，证书路径由环境变量注入）；生产默认 HTTPS，开发可继续 HTTP；
2. JWT 签名密钥由部署侧生成并注入，禁止生产依赖“进程随机密钥”；
3. 空库首次启动生成随机 admin 口令，移除 `admin123` 默认值；**是否强制首次改密改为系统设置中的可开关策略，默认关闭（便于调试）**；
4. 真实的自助修改口令接口 + 前端页面；修改后吊销其他会话；
5. 口令策略（长度/复杂度）统一在校验层，创建/重置/改密共用；
6. 登录/登出/失败登录写入审计（独立 action 与 actor，不再只是匿名 create）；
7. 通用 API 限流（可配置、默认宽松，登录仍保留 5 次/分钟）；
8. compose 基础加固：安全头、no-new-privileges、cap_drop、TLS 证书挂载；
9. 上述能力有单测/构建/浏览器实测与文档。

### 设计调整（2026-10-29，用户反馈）

- 不再默认强制首次改密：`security_settings.force_password_change` 默认 `false`；
- 系统管理 → 系统设置新增「账号安全」卡片，可启用/关闭；
- 开启后仅影响**之后**的新建账号与重置口令；不主动踢出已有会话；
- 登录/`user/info` 返回的 `mustChangePassword` = 用户标记 ∧ 全局开关。

## 验收标准（可测）

- [x] `IPAM_TLS_CERT` + `IPAM_TLS_KEY` 同时存在时控制面以 HTTPS 启动；缺失时 HTTP 并打印显著警告；
- [x] 响应包含 `X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`；HTTPS 时含 HSTS；
- [x] 空库首次启动：生成 ≥16 位随机口令，写入日志/一次性文件（0600）；`IPAM_POC_PASSWORD` 显式设置时沿用；
- [x] 默认策略关闭时登录不要求改密；系统设置开启后，新建/重置账号 `mustChangePassword=true`，登录与 `/auth/user/info` 返回该标记；
- [x] `POST /auth/password`（Bearer）：校验旧口令 → 强度校验 → 更新 bcrypt → 清除 must-change → token_version+1 → 返回新令牌对；旧令牌立即失效；
- [x] 前端：需改密用户登录后出现不可关闭的强制改密弹窗；个人中心“修改密码”真实调用接口；成功后更新 accessToken；
- [x] 口令策略：≥10 位、≤128 位、至少 3 类字符（小写/大写/数字/符号）、不得含用户名、不得与旧口令相同；错误信息明确；
- [x] 登录成功/失败/登出在审计中分别有 `login` / `logout` 动作，actor 为用户名（失败为尝试的用户名），含来源 IP 与结果；
- [x] 通用限流：默认 600 次/分钟/IP，`IPAM_RATE_LIMIT=0` 可关闭；超限 429 + `Retry-After`；
- [x] compose：control-plane 挂载证书、注入 JWT 密钥与 TLS 路径；`no-new-privileges` + `cap_drop: ALL`；install.sh 自动生成密钥与自签证书并用 HTTPS 冒烟；
- [x] `go test ./...`、`vue-tsc`、目标 eslint/stylelint、`pnpm build` 全绿；
- [x] Playwright 实测：开启策略 → 首个账号强制改密 → 重新登录 → 个人中心改密 → 旧密码登录失败；
- [x] 默认关闭策略：登录无弹窗（调试友好），管理页可开启/关闭。
