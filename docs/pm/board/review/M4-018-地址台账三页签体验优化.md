## 目标

在不改动后端契约（`GET /ledger`、`GET /subnets`、`GET /orgs`、`GET /assets`、`POST /ledger/*`）的前提下，
统一优化「DHCP → 地址台账」下三个页签（IPv4 台账 / IPv6 台账 / 资产登记）的信息架构与视觉：

- 每个页签首屏提供与当前对象直接相关的 KPI（容量 / 已用 / 静态 / 保留 / 冲突 / PD / 资产归属）；
- 台账明细补齐搜索、状态/到期筛选、到期剩余提示与空状态；
- 组织树侧栏升级为可搜索、显式「全部组织」、与子网管理页一致的交互；
- 三页统一页头 / 工具条 / 指标卡 / 表格 / 空状态视觉，浅色与深色主题均自适应。

## 验收标准（可测）

- [x] IPv4 台账：4 张 KPI（地址容量 / 已用地址含利用率进度与在线数 / 静态绑定 / 可分配余量），网段上下文条（网关 / DNS / 地址池），在线租约支持关键字（IP/MAC/主机名/使用人）与到期窗口筛选，到期列显示「已过期 / 剩余 x」标签；网络/广播地址不计入可用容量。
- [x] IPv6 台账：4 张 KPI（IPv6 网段 / 在线地址 / PD 委派池 / 当前网段在线），子网表支持关键字与类型筛选，在线租约支持关键字与到期筛选，点击子网行联动切换租约，空状态统一。
- [x] 资产登记：4 张 KPI（资产总数 / 已归属组织含进度 / 使用人数 / 标签覆盖），工具条支持关键字 + 归属范围筛选（全部 / 未归属 / 有标签）+ CSV 导出（导出当前筛选结果、含完整组织路径），所属组织列展示完整组织路径，未归属显式打标。
- [x] 组织树侧栏：搜索组织名、全部组织、点选/再点取消、选中范围提示、重置筛选与空状态；三页行为一致。
- [x] 表格在 1280 宽度不产生横向滚动：IPv4 在线租约去掉低价值「租用时间」列、到期列双行；IPv6 子网表把名称并入 CIDR 单元、去掉 DNS 列；在线租约把 DUID 并入地址单元；资产表把备注并入终端单元、部门并入使用人单元，取消固定操作列。
- [x] 地址矩阵（ip-plan-map）统计条、图例、操作条与页头视觉统一，状态色仍保持六态语义（`STATUS_DISABLED` 改为 `Set`）。
- [x] `vue-tsc` 0 error；改动文件 eslint/oxlint/stylelint 0 issue；`pnpm --filter @vben/web-ipam build` 成功。
- [x] Playwright 登录后逐页截图核对三页（浅色 + 深色），1280/1440/1600 无页面级横向滚动、表格 `scrollWidth == clientWidth`；筛选、刷新、登记/删除、CSV 导出全部实测通过。
