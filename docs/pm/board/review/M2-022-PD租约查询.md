## 方案

经 kea-ctrl-agent 的 lease_cmds hook 实时查询 PD 租约（不入库——Kea memfile 无 DB）：
1. kea engine：CtrlAgent.Lease6List（lease6-get-all → leases 投影：ip-address/type/prefix-len/duid/iaid/cltt/valid-lft）
2. spec：GET /dhcp/leases6（DhcpLease6 列表）+ gen
3. dhcp 模块：ListDhcpLeases6 handler（lease6List 函数注入，与 apply 同款）
4. 前端：子网页 PD 租约卡（只读列表 + 刷新）

## 前置验证（已实证）

- hooks-libraries 加载：kea-dhcp6.conf 模板 + BuildConfig6 base 双侧（键名必须 "library"）
- 命令链闭环：lease6-add（subnet-id/ip-address/type:"IA_PD"/prefix-len/duid/iaid）→ lease6-get-all 回读 ✓
