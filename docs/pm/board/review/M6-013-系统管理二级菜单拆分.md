## 背景

M6-001 后「系统设置」页承载了组织、品牌、账号安全、服务运行、日志存储五类内容，页面过长、入口不清晰。按用户反馈拆为多个二级菜单，降低单页认知负担并便于后续扩展（License/备份/告警等）。

## 目标

- `/system/orgs` 组织管理
- `/system/users` 账号管理
- `/system/roles` 角色管理
- `/system/security` 账号安全（强制改密开关、口令策略）
- `/system/branding` 站点品牌（名称/图标/实时预览）
- `/system/runtime` 服务与运行（端口/版本/依赖/宿主资源/重启）
- `/system/about` 关于平台
- 旧 `/system/settings` 301/重定向到 `/system/orgs`，不破坏书签
- 日志存储不再在系统管理重复，保留跳转 `/logs-center/storage`

## 验收标准

- [x] 账号安全页：开关加载/保存、固定策略说明、4 KPI；
- [x] 站点品牌页：名称/图标/1:1 裁剪/实时预览/保存；
- [x] 服务与运行页：端口/版本/依赖/宿主资源/重启二次确认/日志存储跳转；
