## 背景

M6-017 内置 CSP 为兼容 Vben 的 `IconifyIcon` 运行期取图，在 `connect-src`/`img-src` 放行了
`api.iconify.design` 等公网 CDN。产品面向内网/离线交付，运行期访问外部 CDN 既不可用（断网即
图标缺失）也不安全（对外连接、CSP 放行面）。需将所需图标集合**构建期离线打包**，运行期零外链。

## 目标

1. 扫描前端与 Vben 上游源码中用到的 iconify 图标名，从 `@iconify/json`（MIT，本地依赖）提取**子集**，
   生成离线集合并在应用启动时 `addCollection` 注册；
2. 删除 CSP 中对 iconify 公网 CDN 的放行（`connect-src`/`img-src` 收敛为 `'self'` 等）；
3. 断网/离线场景图标完整渲染；
4. 提供可再生脚本与 `--check` 门禁，防止后续新增图标未纳入、或重新引入外部依赖。

## 验收标准

- [x] `scripts/gen-offline-icons.mjs` 可扫描源码生成 `offline-icons.generated.ts`（按前缀/名称排序，确定性）；
- [x] 应用启动早期注册离线集合，`IconifyIcon` 不再触发网络请求；
- [x] M6-017 默认 CSP 移除 iconify 公网域（`connect-src 'self'`、`img-src 'self' data: blob:`）；
- [x] `scripts/check-webui-offline.sh` 新增断言：产物内置离线图标集合（外链加载面=0）；
- [x] `--check` 模式：重新生成与已提交文件一致，否则非零退出（CI 门禁）；
- [x] 构建产物中无 iconify 运行期外部请求；浏览器实测图标正常渲染（含侧栏/表格/按钮/登录页）；
- [x] `pnpm test`、`vue-tsc`、build 绿；E2E 15/15；
- [x] 文档同步（实现说明、进度日志、运维手册 CSP 章节更新）。

## 设计取舍

- 只提取**用到的图标子集**而非整包（lucide 全量 543K、mdi 3.4M），控制体积；
- 保留 `@iconify/json` 为**构建期**依赖（生成脚本用），运行期产物只含子集 JSON；
- 动态拼接/变量引用的图标无法静态扫描：生成脚本对未命中的可疑名告警；开发者新增图标需重跑生成器；
- `svg:` 前缀为 Vben 本地 SVG（已离线），不纳入。
