## 目标

补齐 M2 里程碑出口「资产登记」能力：在地址台账下新增「资产登记」页签，以 MAC 为身份键管理使用人 / 部门 / 备注 / 标签，
换址不丢，为日志中心提供「终端 → 组织」关联链；同时修复实现中暴露的两个后端缺陷（assets 权限域错配、tags 非空列写入）。

## 实施记录（追加式，勿删旧条目）

### 2026-10-19 · 会话1

- **做了什么**：
  - 新增资产登记页 `views/dhcp/ledger/assets.vue`：组织树侧栏 + 关键字工具条 + 资产表格（MAC/使用人/部门/所属组织/标签/备注/操作）+ `useVbenModal` 登记/编辑表单；MAC 经 `normalizeMacInput` 归一化，编辑态只读。
  - 新增路由 `DhcpLedgerAssets`（`/dhcp/ledger/assets`，authority `assets:read`）挂到地址台账父路由，形成 IPv4/IPv6/资产登记 三页签；补齐中英 locale。
  - 扩展 `api/ipam.ts`：`listAssets({orgId,q})`、`upsertAsset`、`deleteAsset`、`AssetUpsert` 类型。
  - **后端修复①（rbac）**：`domainOf` 曾把 `/api/v1/assets` 并入 `dhcp` 域，导致仅持 `assets:*` 的自定义角色无法读写 `/assets`、角色管理里的 assets 权限点形同虚设；改为独立 `assets` 域。
  - **后端修复②（tags）**：`PgAssetRepo.Upsert` 在标签缺省时把 nil 直传驱动，被编码为 NULL 覆盖 `tags NOT NULL DEFAULT '{}'` 而报错；服务层 `normalizeTags` 规整为空数组，前端亦恒传数组。
- **改动文件**：见「涉及模块」。
- **验证结果**：
  - `go build ./...`、`go vet` 0 错；`go test ./...` 全绿（含新增 `TestDomainOf_资产域独立`、`TestRBAC_资产域按assets权限拦截`、`TestAssetUpsert_无标签规整为空数组`）。
  - 前端 `vue-tsc` 0 error、`pnpm --filter @vben/web-ipam build` 成功；改动 vue 文件 eslint 0 issue、oxlint 0。
  - 实测后端接口：`PUT /assets`（MAC 归一化）200、`GET /assets?q=` 过滤、`DELETE /assets/{mac}` 204。
