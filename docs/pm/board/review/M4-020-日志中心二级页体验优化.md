## 目标

日志中心由 3 个二级页（查询检索 / 实时流 / 操作审计）扩展为 5 个，并在**不改动后端契约**的前提下重写全部页面：

- 新增 **日志概览**（`/logs-center/overview`）：一眼看清时间窗内事件规模、趋势、TopN 与最近操作。
- 新增 **存储与归档**（`/logs-center/storage`）：把原「系统设置」里的日志存储/归档能力抽出为独立页，并抽成共享组件供系统设置复用。
- 统一 `PageHeader` + 4 张 KPI `StatCard` + `ipam-toolbar` / `ipam-filter-grid` + 统一空状态与深色主题；补齐时间预设、条件记忆、详情抽屉、CSV/TXT 导出、断线重连等商业软件常见能力。

复用既有端点：`/logs`、`/logs/top`、`/logs/qps`、`/logs/export`、`/logs/tail`、`/audits`、`/system/log-settings`、`/system/log-archives*`。**本次无 API 契约变更**（仅前端类型导出补齐 + `openLogTail` 参数扩展，均对应 spec 已有字段）。
