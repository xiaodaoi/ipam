## 目标

bind（静态绑定）从 reservation-add 命令式改为配置式：kea BuildConfigFull 投影子网 reservations 段（{ip-address, hw-address}），统一走 config-set 原子语义（与选项/类一致）。

## 验收标准（可测）

- [ ] BuildConfigFull 按地址归属子网投影 reservations（单测锚定 JSON）
- [ ] BulkReservations 回滚缺口修复（bind Upsert 与 kea 失败同事务）
- [ ] 废弃 ctrl.go BindStatic 命令路径（删除或标注）
- [ ] e2e：bulk bind → config-set 成功 → 租约匹配 host reservation

## 涉及模块

- internal/engine/kea/config.go（reservations 投影）
- internal/module/ipam/ledger_handler.go（bind 路径 + 回滚）
