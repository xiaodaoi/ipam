## 目标

在不改变业务逻辑与 API 契约的前提下，为 IPAM 全部一级/二级菜单页面建立统一视觉语言：
页面骨架、页头信息层级、卡片/表格/工具条密度、指标与状态表达一致，提升可读性、可操作性与商业交付观感。
