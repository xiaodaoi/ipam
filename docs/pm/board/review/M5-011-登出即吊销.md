## 方案

- TokenBlacklist（内存黑名单）：令牌 SHA256 指纹 → 过期时刻；条目 TTL = 令牌剩余寿命（自然过期自清）
- LogoutAuth：有效令牌入黑名单至自然过期（无效令牌幂等 ok）
- RBAC 中间件：黑名单检查（ParseJWT 后）——已吊销令牌 → 401 TOKEN_REVOKED
- 重启清空（PoC 语义，多实例/持久化黑名单为后续卡）
