## 目标

日志中心「查询检索」界面支持按 **域名、客户端（MAC）、应答 IP、来源 IP** 的模糊（子串、不区分大小写）搜索，提升威胁排查与终端定位效率。

## 验收标准（可测）

- [x] `/logs`、`/logs/export`、`/logs/tail` 支持 `sip` 参数（来源 IP 子串）
- [x] `mac` 由精确匹配改为子串（模糊）匹配；`domain`/`answerIp` 保持子串
- [x] CH 与内存两种 Store 过滤语义一致（含占位符对齐）
- [x] 检索页新增「客户端MAC（模糊）」「来源IP（模糊）」输入，域名/应答IP 提示改为（模糊），查询与导出均带新参数
- [x] `go build` / `go test ./...` 绿、`vue-tsc` 0 error

## 实施记录（追加式，勿删旧条目）

### 2026-10-16 · 会话1

- **Spec 先行**：`parameters/logs.yaml` 新增 `LogSip`（来源 IP 子串），`LogMac`/`LogAnswerIp` 描述改为子串（模糊）；`paths/logs.yaml` 将 `LogSip` 接入 `listLogs`/`exportLogs`/`streamLogTail`，并在集合描述注明模糊语义；`make gen` 再生 api/gen 与 schema.d.ts。
- **后端**：`LogFilter` 增 `SIP`；`ch_store.go` 的 `buildWhere` 将 `client_mac = ?` 改为 `positionCaseInsensitive(client_mac, ?) > 0`，新增 `positionCaseInsensitive(toString(sip), ?) > 0`；`mem_store.go` 的 `matchLog` 同步为子串（MAC/SIP）；`handler.go` 三端点读取 `params.Sip`（tail 的轮询 Query 透传 SIP）。
- **前端**：`LogQuery` 增 `sip`；检索页新增「客户端MAC（模糊）」「来源IP（模糊）」输入，`loadLogs`/`onExport` 带上 `mac`/`sip`；用 `eslint --fix` 规整该文件 import/顺序，文件达成 oxlint+eslint 0 issue。
- **测试修复**：`logquery_test.go` 原 `now` 硬编码 `2026-08-26`，早已超出 `validateWindow` 31 天窗口导致整包失败；改为锚定「过去某小时 :30」的滚动时间（既在窗口内又保证同整点），并新增 `TestMatchLogFuzzy`；`sql_builder_test.go` 增补部分 MAC 与 SIP 用例。
- **验证**：`go test ./...` 全绿（此前后端全绿，本次到齐）；`vue-tsc` 0 error；`golangci-lint run ./internal/module/logquery/...` 0 issues。
- **遗留**：`ip-plan-map.vue` 等历史文件仍有大量既有 eslint 规则告警（未在本次范围）。
