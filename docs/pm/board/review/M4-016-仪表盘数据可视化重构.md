## 目标

在不改变后端契约（`GET /dashboard`、`GET /system/metrics`、`GET /logs/qps`）的前提下，重构运行概览页的
数据表达：用统一的可交互图表替代「div 柱子 + 拉伸 SVG」，用环形指标与排名列表替代大面积空白表格，
使关键指标可读、可比较、有上下文。

## 实施记录（追加式，勿删旧条目）

### 2026-10-28 · 会话1

- **做了什么**：重构仪表盘数据表达，替换「div 柱状 + preserveAspectRatio=none 拉伸 SVG + Ant Table」的旧呈现。
- **新增组件**：
  - `components/trend-chart.vue`：纯 SVG 折线/柱状图，含 Y 轴刻度、虚线网格、均值/峰值参考线、单调三次插值（不过冲）、面积渐变、末端脉冲点、悬浮十字线 + 时间/数值气泡；宽度用 `useElementSize` 实测，避免拉伸变形。
  - `components/metric-ring.vue`：环形指标（stroke-dasharray + 圆头），支持空值占位与主题色。
- **扩展组件**：`components/stat-card.vue` 增加 `spark`（迷你趋势线）/`sparkTone`，趋势文案移到数值行内，底部提示用 `margin-top:auto` 对齐。
- **页面重构**（`views/dashboard/ipam/index.vue`）：
  - KPI 4 卡：活跃终端、5 分钟 QPS（均带 24h/近 30 桶迷你趋势）、服务健康（进度条）、今日拦截；数值统一千分位。
  - 活跃终端趋势：柱状图 + 峰值标注 + 今日新增/离线/小时均值/双栈联动成功率摘要行。
  - 核心服务健康：环形 4/4 + 服务清单 + 说明。
  - DNS 查询量：折线面积图 + 1h/6h/24h 分段切换（`intervalSec` 60/300/900）+ 平均/峰值速率（统一折算次/分）与区间总量。
  - 新增「热门查询域名 Top5」（复用 `GET /logs/top?by=domain`，近 1 小时），带占比条与日志明细跳转。
  - 主机资源：CPU/内存/根分区环形 + 磁盘紧凑条 + 1/5/15 分钟负载与连续运行。
  - 地址池利用率：排名列表（名次徽标、CIDR、利用率条、已用/容量），附子网管理跳转。
  - 首屏 `Skeleton` 占位，替换原先加载期闪现的空状态。
- **数据口径修正**：剔除末尾「进行中」分桶（终端按小时、QPS 按当前 `intervalSec`），避免趋势尾部假下跌。
- **样式**（`styles/index.css`）：新增 `ipam-card-title/legend/chip/seg/figure/ring/chart/rank/disk/gauge` 等约 400 行，全部走 Vben 主题变量，明暗自适应。
- **验证**：`vue-tsc` 0 error；eslint + oxlint + stylelint 0 issue；`pnpm --filter @vben/web-ipam build` 成功；Playwright 实测 1600/1280/820 三档、深浅色主题、柱/折线悬浮气泡与 24h 区间切换均正常。
- **遗留**：未重建 control-plane 镜像（当前容器内嵌的是上游 Vben 旧产物，部署后才会生效）。
