## 目标
- 业务 API 增加统一 fetch：15s 超时、401 清令牌并弹登录过期；SSE/下载复用同一鉴权入口。
- 启用 refresh token 自动续期。
- 登出改走带 Authorization 的 `requestClient`，并提交 refreshToken，后端可真正吊销会话。

## 改动范围
- `web/apps/web-ipam/src/{api/ipam.ts,api/core/auth.ts,preferences.ts}`

## 验证
`vue-tsc`、`pnpm run build:ipam`、i18n 门禁通过。

## 遗留
登录流程未见持久化 refreshToken 的改动，刷新仍可能走降级路径；需真实 24h 会话验证。
