## 目标

把双栈 MAC↔DUID 关联方式抽象为模板级可选项 `matchScheme`，option79 为 auto 链首选，并提供老旧交换机可用的降级（client-id / duid-llt / hostname）与人工兜底（admin 映射 + kea6 预留），使客户端首次分配即得规范 v6。

## 验收标准（可测）

- [x] `prefix_template.match_scheme` 迁移 + 枚举校验；存量模板 = auto（零破坏）
- [x] `dualstack_identity` 表 + 精确方式自动学习落表（hostname 不落表）
- [x] 对账器方案链：admin→option79→client-id→duid-llt→hostname→冲突；钉死方案拦截跨方案回落
