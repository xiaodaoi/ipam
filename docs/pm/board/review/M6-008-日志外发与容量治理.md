## 已完成

- **外发通道**（Vector sink，按需启用）：
  - Syslog（socket + RFC5424，TCP/UDP）；
  - Kafka（brokers/topic，JSON）；
  - Webhook（HTTP POST，newline-delimited JSON）。
- **采样策略**：全量 / 1/N 抽样 / 仅异常（非 INFO）；同时作用于 ClickHouse 入库与全部外发 sink。
- **配置渲染与热加载**：控制面把 DB 策略渲染到共享卷 `vector-config`，Vector `--watch-config` 自动重载；模板与生成配置分离，重启不丢。
- **管理页**：日志中心 → 外发与采样；4 KPI、通道开关/地址、采样模式/比例、根分区水位提示。
- **部署**：新增 `vector-config` 卷、volume-init 权限、control-plane 依赖；模板只读挂载。
- **校验**：渲染配置通过 `vector validate`；单测覆盖渲染/模式/参数校验。

- 验证：control-plane 重新渲染后 Vector 热加载成功；容器内 `curl vector:9598/metrics` 实测出现 `vector_buffer_byte_size/events`、`vector_component_received/sent_events_total`、`vector_utilization` 等指标；`vector validate` 通过。

### 2026-10-31 · 磁盘水位自动降级

- 新增 `logexport/watermark.go`：每 1 分钟检查根分区，连续 3 次 ≥90% 覆盖采样为 `errors`，连续 3 次 ≤85% 恢复（回差防抖）。
- 覆盖仅在渲染层，不修改用户保存的策略；`Status` 暴露 `effectiveSamplingMode/degraded/diskUsedPercent/degradedAt`，随 `GET/PUT` 返回。
- `/metrics` 新增 `ipam_log_export_degraded`，`alerts.yml` 新增 `IpamLogExportDegraded`。
- 前端外发页展示生效模式、自动降级状态与恢复说明。
- 验证：logexport 单测（覆盖/恢复/保存不丢/防抖/env）、lint、vue-tsc/eslint、E2E。
