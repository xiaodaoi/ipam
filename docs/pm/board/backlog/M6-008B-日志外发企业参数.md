## 目标

补齐企业环境外发通道的安全与可运维参数，不改变现有基础外发行为：

1. **Syslog TLS**：CA 证书、客户端证书/私钥、SNI、`verify` 开关；
2. **Kafka SASL/TLS**：`SASL/PLAIN`、`SASL/SCRAM-SHA-256/512`、TLS CA 与跳过校验开关；
3. **Webhook 鉴权头**：自定义 Header（如 `Authorization`），值加密存储、界面脱敏；
4. **外发通道「测试发送」**：按当前配置发送一条样例事件，返回各通道结果与错误摘要。

## 设计约束

- 证书/口令不入库明文：复用 `/run/secrets` 或加密字段（与 M6-001 密钥红线一致）；
- 渲染到 Vector 配置时使用环境变量引用，不把私钥写进 `vector.toml`；
- 界面遵循 M6-031 术语规范：默认界面不出现 Vector 等底层组件名，Syslog/Kafka 等协议名可保留；
- 测试发送必须限流并留审计记录。

## 验收标准

- [ ] Syslog over TLS 可配置 CA/客户端证书，`verify=false` 时明确风险提示；
- [ ] Kafka SASL/PLAIN 与 SCRAM 可配置，口令脱敏展示；
- [ ] Webhook 自定义 Header 可配置，保存后不回显明文；
- [ ] 「测试发送」对每个启用通道返回成功/失败与错误摘要，并写审计；
- [ ] 渲染配置通过 `vector validate`；单测覆盖参数校验与脱敏；
- [ ] 文档：运维手册「日志外发」补充 TLS/SASL 配置示例与排障。
