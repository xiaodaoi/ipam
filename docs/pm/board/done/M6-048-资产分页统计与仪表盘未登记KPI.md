## 问题

1. `/assets` 全量返回，前端分页 + 前端算 KPI：终端上千后列表慢、KPI 只统计当前页/筛选后内存数据。
2. 关键字 `%kw%` 无法走 B-tree，规模上来后每次查询全表扫描。
3. 仪表盘看不到"还有多少终端没登记"，登记率只能靠人工对照发现页与资产页。

## 验收标准

- [x] `GET /assets` 服务端分页（`page/pageSize`，上限 200），`total` = 筛选后总数。
- [x] 同条件服务端统计 `stats{total,assigned,unassigned,owners,depts,online,offline,tagged}`，与分页解耦。
- [x] `scope=all|unassigned|tagged` 与 `online=true|false` 均下推 SQL；在线集合按身份键 `identity/mac/duid ANY(...)`。
- [x] 迁移 `0053_asset_trgm`：pg_trgm + owner/dept/mac/duid/去分隔符 MAC 表达式索引。
- [x] `DashboardOverview` 新增 `unregisteredTerminals/ignoredTerminals/assetTotal`；未登记数与发现页一致（复用 `Discover`）。
- [x] 资产页切页/改筛选均重新请求且回第 1 页；CSV 按当前筛选最多导出 500 条。
- [x] 仪表盘五卡布局 + 「未登记终端」卡（登记率/已登记/忽略）；zh/en 成对。
- [x] 单测 + E2E 覆盖；文档同步。
