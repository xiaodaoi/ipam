## 目标

让日志存储周期成为系统设置中的可配置项（按天，默认 180，可修改），并支持按月导出 Parquet 归档备份与归档文件管理（下载/删除），实现"自动滚动删除 + 按月备份"的完整生命周期闭环。

## 验收标准（可测）

- [x] 系统设置可配置日志保留天数（1-3650，默认 180），保存后 ClickHouse TTL 立即生效
- [x] 可配置归档保留月数（默认 12）与自动导出开关（默认开）
- [x] 存储概览：总行数 / 磁盘占用 / 最早月份 / 当前 TTL / 按月分区明细
- [x] 按月导出为 Parquet（HTTP `FORMAT Parquet`，无需 FILE 权限）
- [x] 归档列表：月份 / 行数 / 文件大小 / 来源 / 导出时间
- [x] 归档下载（Parquet 文件流）与删除（同时清理文件与记录）
- [x] 自动导出：每月 1 日 02:00 导出上月（未归档时）
- [x] 过期归档自动清理（按归档保留月数）
- [x] 手动导出/删除后列表与概览同步刷新
