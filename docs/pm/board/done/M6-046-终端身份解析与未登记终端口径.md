## 问题

1. **IPv6-only 终端整批丢失**：`coherence_binding` 用 DUID 填充 `mac` 列、`ipv4=0.0.0.0`；`NormalizeMAC` 只接受 12 位 hex，`Discover` 遇空 MAC 直接丢弃 → 170/278 台不可见。
2. **DUID 终端无法登记**：`asset` 以 `mac` 为主键，`Upsert` 只收 MAC。
3. **MAC 搜索不带冒号查不到**：库里存 `68:8f:c9:…`，查询用 `%688fc9%` 直接不匹配。
4. **删除不存在的资产仍返回 204**：PG 未检查 `RowsAffected`，与 spec 的 404 不一致。
5. **状态判断写错 + 无过期校验**：过滤 `state == "inactive"`（CHECK 约束里不存在），且不校验 `cltt+valid_lft`。
6. **发现列表无上下文**：没有子网/组织，登记时也无法从子网带出组织。
7. **审计缺 before 快照**：`/assets/:mac` 未注册 `RegisterBefore`。

## 目标

- DUID 终端能发现、能登记、能搜索（映射优先、启发式兜底、DUID 身份兜底）；
- 同一设备 v4/v6 合并为一条，只认 active/grace 且租期未过；
- 契约先行（identity/duid/subnet/orgId），前端 zh/en 成对；
- 用 E2E 数字下界锁死"整批丢失"这类回归。
