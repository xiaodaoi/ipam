# [M6-041] DNS 上游默认池与规则多选

| 字段 | 内容 |
|---|---|
| ID | M6-041 |
| 状态 | done |
| 里程碑 | M6 商业化就绪 |
| 来源 | 用户反馈：默认转发 `.` 只取最早一条上游，单个公网 DNS 故障即导致未命中缓存的公网域名 SERVFAIL；条件转发规则 UI 只能选一个上游 |
| 负责 | opencode(backend/frontend/doc-writer) |
| 创建 | 2026-11-20 |
| 更新 | 2026-11-20 |

## 目标

把默认转发 `.` 从「第一条 enabled 上游」改为「所有标记为默认公共出口的 enabled 上游」，让公网解析具备多地址冗余；同时条件转发规则编辑支持多选上游，并在界面上修正权重等误导文案。内网 DNS 不得进入 `.` 的约束保持不变。

## 验收标准（可测）

- [x] `upstream` 表新增 `is_default` 列（迁移 0050），旧库升级后默认 false。
- [x] `forward-zone "."` 渲染/下发包含所有 `enabled AND is_default` 上游的全部地址（去重）；无任何默认标记时回退到第一条 enabled 上游（兼容旧部署）。
- [x] 标记为默认的上游地址必须全部为公网地址；含 RFC1918 / 环回 / 链路本地 / ULA 等私网地址时拒绝保存（400）。
- [x] 上游列表/表单展示「默认公网出口」开关，可创建、编辑、回显。
- [x] 条件转发规则编辑支持多选上游，创建与更新均按所选集合下发。
- [x] 权重文案明确为「预留字段，暂不参与选路」，不再声称影响被选中概率。
- [x] 契约先行：`api/openapi` 增补 `isDefault` 后 `bash scripts/gen-openapi.sh` 再生 Go/TS。
- [x] Go 单测覆盖：默认池选择（含回退）、私网默认校验、多上游渲染。
- [x] 前端 typecheck / lint / i18n 门禁通过。
