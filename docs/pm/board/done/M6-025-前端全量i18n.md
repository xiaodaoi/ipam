## 目标

把 `web/apps/web-ipam` 业务页面中硬编码的中文全部抽到 locale 文件，提供完整英文，
语言切换即时生效且刷新后保持；中文文案逐字保持不变（E2E 与既有用户习惯依赖）。

### 2026-11-04 · 会话2（全量收口）

- **剩余模块全量抽取**：`dhcp`（7 文件）、`dhcp/ledger`（5 文件）、`dns`（6 文件）、`logs`（6 文件）、`system`（8 文件）、`components/{ip-plan-map,log-storage-panel}`、`views/_core/about`、`layouts/auth.vue`、`views/_core/authentication/login.vue`。
- **locale 规模**：8 个新命名空间文件、2573 条中文文案（zh 与 en 各一份，key 结构对称）。
- **机制修正**：
  - 展示型常量（表格列、状态映射、Tab、选项、统计卡）一律由模块级常量改为 `computed`，否则切换语言不生效；`views/_core/profile/index.vue` 的 tabs 即由 `ref` 改 `computed` 修复。
  - `toLocaleString('zh-CN')` 统一改 `toLocaleString()`，避免英文界面出现中文日期格式。
  - vxe 表格在语言变化后 `setState(...)` 同步列头/空态文案（5 处，类型断言收敛到一次）。
- **语言偏好持久化**：上游 `initPreferences()` 合并策略使默认 `app.locale=zh-CN` 永远覆盖缓存，刷新后语言回退。新增 `src/utils/persisted-locale.ts`（`localeStorageKey/parsePersistedLocale/readPersistedLocale`），在 `main.ts` 的 `initPreferences()` 之前读取 `preferences-locale`，初始化后 `updatePreferences({app:{locale}})` 回填。未修改上游包。
- **文案一致性校验**：脚本回溯 `git diff` 中 2455 条被替换中文片段，逐条比对 zh-CN locale 值，发现并修正 1 处改写（`类名为` → 原文 `类名是`）；其余差异仅为 HTML `&#10;` 换行实体与日志下载表头里的字面 `\n`。
- **门禁结果**：
  - `check-ui-i18n.py` → `OK: UI 文案无硬编码中文（扫描 71 个文件）`
  - `check-i18n-keys.py` → `OK: locale key 结构一致（9 个文件）`

  - `sync-webui.sh --build` 11 任务成功（5.4M）；镜像 healthy
  - web 单测 7 文件 / 33 用例通过（`vitest run --dom`）
  - E2E 16/16 通过
  - 语言切换脚本（`/tmp/opencode/i18n-switch.mjs`）：zh→en 即时生效、刷新保持、个人中心 Tab/安全设置、DHCP/DNS/日志/系统四个业务页抽样、切回 zh 并刷新保持，全部通过。

## 遗留与边界

- 后端响应中的中文错误消息未做 i18n（属服务端任务，前端仅透传 `error.message`）。
- `en-US` 数字/日期使用浏览器区域设置，未按 locale 强制格式化（避免与后端时间串解析冲突）。
- 新增文案时须同时补 zh-CN 与 en-US，并跑两个门禁脚本（已写入规范文档 §6）。
