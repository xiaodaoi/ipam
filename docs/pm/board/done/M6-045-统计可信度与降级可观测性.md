## 问题

1. **降级抽样丢异常**：`ch_out` 是 `type=sample rate=N`，对整个流均匀抽样，磁盘降级时 WARN/ERROR 也只有 1/N 入库，恰好丢失排障最需要的日志。
2. **离线口径与在线不一致**：`offlineTerminals` 仍是「今日 0 点后未见」，凌晨会出现“在线 278、离线 22”的观感矛盾；且不排除“日志未刷新但租约仍有效”的设备。
3. **租约口径含宽限/过期**：`onlineNow` 把 `grace` 也算在线，而台账页 `state=online` 不含宽限；`cltt+valid_lft` 已过期但状态未翻转的绑定也会被算作在线。
4. **抽样不可见**：降级期间 QPS/拦截/趋势都是抽样下界，但仪表盘与日志概览没有任何提示。
5. **无回归门禁**：口径一致性靠人工比对（本次就是这样发现 49 vs 103 的），E2E 只校验文案。

## 目标

- 降级只降低 INFO 写入量，WARN/ERROR 全量入库；
- 在线租约只认 `active` + 租期未过，与台账六态、子网页一致；
- 离线 = 近 24h 有活动且当前无有效租约（按 MAC 归一比对）；
- 仪表盘/日志概览显示“抽样 1/N，KPI 为下界”；
- E2E 增加数字一致性断言，防同类漂移回归。

## 验收标准（可测）

- [x] 降级渲染为 `ch_err`（非 INFO 全保留）+ `ch_info→ch_sample`（INFO 1/N），clickhouse 扇入二者；正常仍为 `ch_out rate=1`。
- [x] `vector validate` 对降级渲染结果通过。
- [x] `onlineNow/poolUsed` 只统计 `active` 绑定、租期未过、子网/池内；`grace` 与过期绑定剔除。
- [x] `offlineTerminals` = 近 24h 有 DHCP 活动且当前无有效租约的 MAC 数；台账不可用时回退旧口径。
- [x] 新增只读 `GET /logs/sampling`（logs 域），返回 `degraded/ingestSampleRate/diskUsedPercent/degradedAt`。
- [x] 仪表盘与日志概览在降级时显示抽样提示，QPS 卡片与趋势副标题带 `1/N`。
- [x] E2E 断言 `onlineNow = onlineV4 + onlineV6`、`Σ pool.used = onlineNow`、池已用与台账一致。
- [x] 单测覆盖降级链路、宽限/过期剔除、MAC 归一离线判定；zh/en 成对。
