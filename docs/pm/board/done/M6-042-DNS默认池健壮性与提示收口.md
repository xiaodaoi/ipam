## 目标

收口 M6-041 的边界：显式默认池一旦启用，停用后不得回落到非默认上游；上游页明确展示默认池状态；条件转发规则不再接受由默认池托管的 `.`，避免“保存成功但不生效”。

## 验收标准（可测）

- [x] 存在任何 `is_default` 标记时，`.` 只使用 `enabled` 的默认上游；默认全部停用则不回落非默认上游（避免内网 DNS 进入 `.`）。
- [x] 从未标记默认的旧部署仍回退第一条 enabled，行为不变。
- [x] 上游页展示默认池状态：未标记时提示兼容回退；标记但全部停用时明确告警；停用的默认条目显示「已停用」标记。
- [x] 规则表单拒绝创建 `.` 规则并提示由上游默认池管理；服务端同步拒绝（400），spec 已先行说明。
- [x] 单测覆盖显式默认停用不回落、`.` 规则拒绝；前端 typecheck/lint/i18n 通过。
- [x] 文档（§2.3、实现说明、任务卡、进度日志）同步。
