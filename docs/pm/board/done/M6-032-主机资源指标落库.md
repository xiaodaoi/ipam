## 问题

当前 `hostmetrics.Collector` 只在被请求时即时采集，**不落库**：

- 仪表盘/运行页只看到瞬时值，客户问「昨晚 2 点是不是 CPU 打满」无法回答；
- 控制面重启后一切归零；
- 采集器被 3 个调用方（`GET /system/metrics`、`/metrics` 抓取、磁盘水位判断）并发调用，CPU 使用率按「任意两个调用者的间隙」计算，数值本身不稳定。

## 目标

- 主机指标（CPU/内存/磁盘/负载）+ 控制面指标（goroutine/堆内存/连接池/日志新鲜度）按 60s 采样落 PostgreSQL，保留 30 天；
- 先修采集器并发问题：改为**单写者 + 快照缓存**，HTTP/Prometheus/水位判断统一读缓存；
- 提供历史序列与汇总两个只读端点，带点数上限保护；
- 备份不包含指标数据行，避免跨机器恢复后出现「上一台机器」的历史。

## 方案

| 项 | 设计 |
|---|---|
| 存储 | PostgreSQL（同库），与 `subnet_utilization` 同款 Repo 模式；不选 ClickHouse/Prometheus |
| 表 | `system_metric`（标量，`UNIQUE(node, ts)`）+ `system_disk_metric`（挂载点明细，级联删除） |
| 采样 | 60s，整分钟对齐；`IPAM_SYS_METRIC_INTERVAL` / `IPAM_SYS_METRIC_RETENTION`（默认 720h） |
| 清理 | 每小时 Prune 一次；失败仅记日志 |
| 降采样 | 查询侧 `date_bin()`，返回点数 ≤ 720 |
| 备份 | `pg_dump --exclude-table-data=system_metric --exclude-table-data=system_disk_metric` |
| 节点 | `node` 列默认 `local`，为 M6-003B 双机预留 |

## 实施记录（追加式，勿删旧条目）

### 2026-11-05 · 会话1

**做了什么**

1. **前置修复（单写者采集）**：`hostmetrics.Collector` 由「每次调用各自采样」改为 `Start` 后台协程独占 `Sample`，结果写 `atomic.Pointer` 快照；新增 `Snapshot()`（读缓存，无磁盘 IO）与 `Valid()`（是否已拿到两次读数差值）。`GET /system/metrics`、`/metrics`、磁盘水位判断全部改读快照，CPU 使用率恢复为固定间隔差值；`IPAM_HOST_SAMPLE_INTERVAL` 默认 5s。
2. **迁移 0043**：`system_metric`（宿主 + 控制面标量，`UNIQUE(node, ts)`）+ `system_disk_metric`（挂载点明细，`ON DELETE CASCADE`）；已在真实栈应用（`schema_migrations` 最新 = `0043_system_metric`）。
3. **新模块 `internal/module/systemmetric`**：`Repo` 接口 + `MemRepo`（PoC/单测）/`PgRepo`（`date_bin` 序列、峰值汇总、`Earliest`、`Prune`）；`Service.Sample/Run`（60s、整分钟对齐、首个样本跳过、DB 失败只记日志、每小时最多 Prune 一次）；`NormalizeRange`（step ≥60s、窗口 ≤90 天、点数 ≤720 自动放大）；`RuntimeStats` 用 `runtime/metrics` 读 goroutine/堆。
4. **API**：`api/openapi/openapi.yaml` 新增 `/system/metrics/history`、`/system/metrics/summary` 与 `SystemMetricPoint/History/Summary` schema，`bash scripts/gen-openapi.sh` 再生；`MetricHandler` 暴露两端点，响应头回带 `X-Metric-Window-From/Step`；权限沿用 `dash:read`。
5. **装配**：`cmd/control-plane/main.go` 启动采集协程、注入 `Host/DBPool/LogLatestAge`、挂载 handler；`IPAM_SYS_METRIC_INTERVAL`、`IPAM_SYS_METRIC_RETENTION`。
6. **备份边界**：`internal/module/backup/pg.go` 抽出 `dumpArgs()`，加 `--exclude-table-data=system_metric` / `system_disk_metric`（结构保留、数据排除）。
7. **前端**：`views/system/runtime/index.vue` 新增「历史趋势」卡片（1h/6h/24h/7d/30d，4 张 TrendChart、峰值行、控制面 4 项）；`api/ipam.ts` 新增两个客户端；zh/en `system.json` 成对新增 `runtime.history.*`。
