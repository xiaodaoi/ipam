## 目标

1. kea-dhcp4 改为 hostNetwork，与 kea-dhcp6/unbound 统一，消除桥接 + docker-proxy 带来的源地址 NAT 与广播可见性隐患。
2. 新增免鉴权只读品牌端点，使**登录页（鉴权前）**也显示站点名称/图标。
3. 双栈模板「编码」下拉隐藏后端尚未实现的 `CUSTOM`，避免用户选中后保存报错。
