## 问题

1. 「未登记终端」240+ 条，只能逐条登记；现场常见"一个部门一次上几十台"。
2. 打印机、AP、临时设备永远出现在未登记列表，真正待登记终端被淹没，列表只增不减。
3. 资产页只有使用人/部门/组织，看不到终端当前 IP 与在线状态，实质仍是通讯录。
4. 资产列表组织筛选用 `org_id = $1` 精确匹配，与日志中心子树口径不一致。
5. `asset.mac` 允许为空后，`logquery.PgOrgExpander` 扫描 NULL 会失败（日志按组织过滤 500）。

## 验收标准

- [x] `POST /assets/bulk` 批量登记，部分成功，失败项按 index + code 返回；上限 500。
- [x] 忽略名单 `asset_ignore`（迁移 0052）：`GET/PUT /assets/ignored`、`DELETE /assets/ignored/{identity}`；忽略后不再出现在发现列表，可恢复。
- [x] 忽略同时按 MAC / DUID / identity 生效（先按 DUID 忽略、后解析出 MAC 仍被抑制）。
- [x] `GET /assets` 返回 `ipv4/ipv6/state/online/lastSeen` 与 `onlineCount`，支持 `online=true|false`。
- [x] `online` 与仪表盘在线租约同口径（active 且租期未过）；`state` 取最严重者。
- [x] `GET /assets?orgId=` 按子树展开；未知组织返回空。
- [x] 前端：多选批量登记、行内/批量忽略、忽略名单弹窗与恢复、资产页地址/在线列与筛选、CSV 增列。
