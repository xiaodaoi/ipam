## 问题（实测）

`bash scripts/package-offline.sh` 成功生成交付包，但 `tar -tzf dist/offline/ipam-bundle.tar.gz` 显示：

```
deploy/compose/.env          # 含 POSTGRES_PASSWORD / CLICKHOUSE_PASSWORD / IPAM_JWT_SECRET
deploy/compose/certs/        # 生产环境会含证书与私钥
```

脚本用 `tar -C "$root" ... deploy config db ...` 整目录打包，未排除被 `.gitignore` 忽略的运行时文件。
虽然 `.env` 未入库，但**交付包会把它带到客户现场**，违反 AGENTS.md「密钥/证书/口令不入库」红线
（离线包同样是交付物）。本地 `certs/` 为空，但生产打包时必然存在。

另发现 `dist/`（离线包产物，本次 2.7GB）未被 `.gitignore` 忽略，存在误提交风险。

## 目标

- 交付包不包含 `.env`（除 `.env.example`）、`certs/`、`*.pem/*.key/*.crt/*.p12/*.pfx`；
- 打包脚本自带「命中即失败」校验，防止后续新增文件再次泄漏；
- `install.sh` 仍能在目标机用 `.env.example` 生成 `.env`（安装流程不变）；
- `SHA256SUMS` 校验通过。

## 实施

| 文件 | 变更 |
|---|---|
| `scripts/package-offline.sh` | tar 增加 `--exclude`（`.env`、`certs/`、证书/私钥扩展名）；打包后调用密钥自检脚本 |
| `scripts/check-bundle-secrets.sh`（新增） | 扫描 bundle 条目，命中 `.env`（`.env.example` 除外）/`certs/`/证书私钥即打印命中项并 `exit 1`；可独立用于 CI |
| `.gitignore` | 新增 `dist/`，避免 2.7GB 离线镜像产物误入库 |

排除 `.env` 不影响安装：`deploy/compose/install.sh:30` 在 `.env` 缺失时从 `.env.example` 复制生成。

## 实施记录

### 2026-11-04

**定位**

- 首次打包成功后按「交付物不含密钥」红线抽检 bundle 清单，发现 `.env` 与 `certs/`。
- 同时发现 `dist/` 未忽略：`git status` 显示 2.7GB 未跟踪目录。

**改动**

- `package-offline.sh`：`tar --exclude` 五类敏感项；打包后调用自检，失败即非零退出（不产出 SHA256SUMS）。
- 新增 `scripts/check-bundle-secrets.sh`：独立可测的检查器，输出命中项前 20 条。
- `.gitignore` 增加 `dist/`。

**验证证据**

| 场景 | 结果 |
|---|---|
| 构造含 `.env` + `certs/server.pem` 的包 | `FAIL: 交付包含 .env/证书/私钥`，exit 1 |
| 仅含 `.env.example` 的干净包 | `OK: 交付包不含 .env/证书/私钥`，exit 0 |
| 真实离线包（10 镜像 + bundle，2.7GB） | 自检 OK；清单仅 `.env.example`；`sha256sum -c` 11 项 OK |
| 解包安装目录 | `.env` 不存在、`.env.example` 存在 → `install.sh` 首次安装会生成 `.env` |
