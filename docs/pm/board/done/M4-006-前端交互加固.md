## 实施记录（追加式，勿删旧条目）

### 2026-09-20 · 会话1

- **删除确认**：14 处删除按钮统一包裹 `Popconfirm`（确认/取消文案一致，描述含不可恢复提示）。覆盖 DHCP 模板/选项/分类/子网、DNS 上游/转发/记录/名单及条目、角色、用户、组织节点。组织节点原先用 `window.confirm`，一并统一。
- **站点名称刷新丢失**：根因是 vben `initPreferences` 用 `defu`（首参优先）合并 `merge({}, initialPreferences, cachedPreferences)`，而 `initialPreferences = merge({}, overrides, defaultPreferences)` 含全部默认键——导致 localStorage 缓存在初始化时对**任何已定义键**都无效；站点名存在于服务端 `webui_settings`，故每次刷新被 `VITE_APP_TITLE`（`Vben Admin Antd`）覆盖。用 `defu({}, initial, cached)` 实测确认首参优先。
- **修复**：新增 `utils/site-branding.ts`（`applyBranding` / `applySiteBranding`），在 `store/auth.ts` 的 `fetchUserInfo()`（登录 + 守卫在每次页面加载时调用）后拉取 `/system/webui-settings` 并运行时应用；标题由 bootstrap 的 `watchEffect` 从 `preferences.app.name` 响应式联动。设置页改用同一助手，去掉重复实现。
- **验证**：站点名 `DDI`（服务端）——登录后 / 硬刷新 / F5 刷新标题均为「仪表盘 - DDI」，侧栏为 `DDI`；组织、双栈模板、DHCP 选项三处删除均弹出确认框，取消后行数不变；控制台无错误。
