# 使用指南

## 导航

- **仪表盘**：在线终端、QPS、服务健康、池利用率、主机资源。
- **DHCP 服务**：子网管理、IPv4/IPv6 台账、资产登记、保留与绑定、选项与类匹配、双栈管理。
- **DNS 服务**：上游、条件转发、解析记录、缓存、安全与诊断、封禁管控。
- **日志中心**：概览、检索、实时流、操作审计、外发与采样、存储与归档。
- **系统管理**：组织、账号、角色、账号安全、站点品牌、服务与运行、备份与恢复、授权管理、关于。

## 常见任务

### 新建子网并下发

1. DHCP 服务 → 子网管理 → 新建；
2. 选择组织、族（v4/v6）、CIDR、网关/DNS、地址池；
3. 保存后控制面生成 Kea 配置并下发；
4. 在 IPv4/IPv6 台账查看地址状态。

### 租约查询与操作

DHCP 服务 → 租约管理：

- IPv4/IPv6 分页签，可按 IP/MAC/主机名/DUID 搜索；
- IPv4 支持**延期**（修改 valid-lifetime）、**改绑**（换 MAC/主机名）、**释放**；
- IPv6 支持**释放**（IA_NA/IA_PD）；
- 操作直接作用于 Kea 运行态，无需重启服务。

> 延期/改绑只影响当前租约；长期固定地址请在「保留与绑定」创建 host reservation。

### 地址转静态/保留

台账选中地址 → 转静态（填 MAC）或保留（冻结）；释放后回归动态池。

### 双栈联动

双栈管理 → 模板（v4 CIDR ↔ v6 前缀、编码、匹配方案）→ 冲突清单人工映射；租约联动写入 DNS 正/反记录。

### DNS 封禁

封禁管控 → 名单库（自定义/订阅）→ 策略分组（网段×名单）→ 编译；命中日志在日志中心按 blocked 筛选。

### 账号与权限

- 账号管理：角色可多选（内置/自定义），自定义角色先在角色管理创建并勾选权限；
- 账号安全：强制改密开关、口令策略；
- 个人中心 → 安全设置：TOTP 2FA、注销全部会话。

### 站点品牌

系统管理 → 站点品牌：站点名、1:1 图标实时预览，保存即时生效。

### License

系统管理 → 授权管理：粘贴 License JSON 激活；未激活为社区版。
